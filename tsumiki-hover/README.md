# つみきホバー（カーソルを乗せた窓が前に出る）

カーソルを乗せた窓が前に出て、そのまま操作の対象になる、メニューバー常駐のアプリ。
クリックしなくても、見えている窓に乗せるだけで切り替わる。

| 操作 | 動き |
|---|---|
| 窓に乗せる | 感度（下）に合わせて、その窓**だけ**が前に出る（同じアプリのほかの窓は前に出てこない） |
| 窓と窓のあいだ（デスクトップ）に乗せる | デスクトップが操作の対象になる（Finder の窓を開いたあとでも、Finder の窓は前に出てこない）。何もない所なら1回クリックしたのと同じ動きで選ぶ（アイコンの上・ステージマネージャ／「壁紙クリックでデスクトップ表示」がオンのときはクリックしない）。Finder を除外すると何もしない |
| control を押しているあいだ | 止まる（押したまま別の窓を通り抜けられる） |
| ⌃⌥⌘H | オン・オフ |
| メニュー | 休む（15分・1時間）／感度（最速・速い・ふつう・ゆっくり）／いま前にいるアプリで止める／除外の一覧／ログイン時に開く |

## 感度
カーソルを**止めたら**すぐ出し、**動かしている途中**は通り抜けで出さないよう少し待つ。

| 感度 | 止めてから | 動かしている途中 |
|---|---|---|
| 最速 | すぐ | すぐ（通った窓も出る） |
| 速い（既定） | 30ms | 120ms |
| ふつう | 80ms | 250ms |
| ゆっくり | 250ms | 600ms |

## 止まる場面（困りやすい所）
- メニュー（メニューバー・右クリック）を開いているあいだ。カーソルがメニューの外に出ても止まる
- マウスのボタンを押しているあいだ（ドラッグ・範囲選び・窓の移動）
- デスクトップ（スペース）を切り替えた直後の 0.4 秒と、そのあとカーソルを動かすまで
- 浮いている窓（Dock・メニューバー・通知・つみきショットの範囲選びの幕・つみきロックの幕）の上
- 画面の上の縁（隠れたメニューバーが出てくる所）
- 除外アプリが前にいるあいだ、または浮いた窓を出しているあいだ。既定の除外は Alfred・Paste・Spotlight・Raycast・つみきショット・CleanShot X。
  メニューバーに常駐しているだけなら止めない
- 出したのに前に来ないアプリ（出せないアプリ）には、1秒は出し直さない

## 仕組み（公開の仕組みだけ・非公開の関数は使わない）
- 0.01 秒ごとにカーソルの位置を見る。「止めた」は 1pt 未満しか動いていないこと。**動いていなくて待っている窓も無ければ何もしない**（止まっているときの CPU 0.2%）
- カーソルの下の窓は `CGWindowListCopyWindowInfo`（手前から奥の順・高さ（layer）・位置・持ち主）。名前や中身は読まない＝画面収録の許可は要らない
- 高さ 0（普通の窓）だけを出す。101＝開いたメニュー、24・25＝メニューバー
- 前に出す：アクセシビリティで窓を `AXMain`＋`AXRaise`、アプリを `AXFrontmost`。
  `AXFrontmost` はそのアプリの窓を**全部**前に出すので、もともと間にあったほかのアプリの窓を、抜かれたのを見てから奥から順に `AXRaise` で戻す（同じアプリの窓には撃たない＝撃つとまた全部が前に出る。次の窓を出したら古い戻しはやめる）
  （`NSRunningApplication.activate` は裏のアプリから呼ぶと macOS 14 以降は断られて効かない＝試して確かめた）
- 判断（`Engine.swift` の `Brain`）は画面に触らない＝自己テストで架空の様子を流せる
- 要る許可：**アクセシビリティ**だけ。App Store の箱の中（サンドボックス）では取れないので、App Store 版は作れない（下）

## ファイル
| もの | 中身 |
|---|---|
| `main.swift` | メニューバー・設定（UserDefaults `com.tsumiki.hover`）・⌃⌥⌘H（Carbon のホットキー＝許可不要） |
| `Engine.swift` | 判断（Brain）・画面を読む（Screen）・前に出す（Raiser） |
| `SelfTest.swift` | `--selftest`：困りやすい場面を含む35項目。許可不要 |
| `LiveTest.swift` | `--livetest`：子プロセスで本物の窓（3枚の窓を持つアプリを含む）を出して前に出す。カーソルは動かさない。アクセシビリティの許可が要る |
| `Icon.swift` | アイコン（積み木とカーソル）をコードで描く。`--icons <dir>`・`--menu-preview <png>` |
| `build.sh` | 自己テスト（`HOVER_LIVE=1` で本物の窓の試験も）→ `~/Applications/つみき/TsumikiHover.app` |
| `package.sh` / `notarize.sh` | 両方の CPU 用 → Developer ID で署名・公証・staple・spctl → zip（つみきショットと同じ流れ・公証の保存名 `tsumikishot`） |

`HOVER_LOG=1 build/TsumikiHover` で、止めた理由を1行ずつ出す（端末から動かすと端末の許可で動く）。

## App Store 版
作らない。つみきショットの `appstore.sh`・`AppStore.entitlements`・`-D APPSTORE` の形には**乗れない**：
箱の中ではアクセシビリティの許可が取れず（`AXIsProcessTrusted` が常に false）、ほかのアプリの窓を前に出せないため。
一時的な例外の権利（temporary-exception）は審査に通らない。
