つみきリモート
取扱説明書

Mac を眠らせずに置いていき、外出先の iPhone から Claude Code の様子を見て、返事だけ返す。 2026年8月11日に作ったものの、使い方と勘所。

01

何ができるようになったか

いちばん短く言うと、「AIの作業を、家に置いたまま外から見守れる」ようになりました。 これまでは Mac の前を離れた瞬間に作業が止まっていた（＝蓋を閉じると眠る、 止まっても気づけない）のが、離れても止まらず、止まったら手元に知らせが来ます。

BEFORE → AFTER

離席で止まらない

蓋を開けたまま画面だけ消えて、中身は動き続けます。眠らせない仕掛けを常駐させました。

BEFORE → AFTER

待たせない

AIが許可を求めて止まったら iPhone に通知。「はい」を押しに帰る必要がありません。

BEFORE → AFTER

並べて見える

複数の作業を同時に走らせて、どれが止まっているか一覧で分かります。

いちばん効くのは3つめです。AIに任せる作業は「頼む → しばらく放置 → 聞かれたら答える」の 繰り返しなので、人間の役割はだんだん「作業者」から「見守り役」に寄っていきます。 見守り役は机の前にいる必要がありません。移動中でも、待ち時間でも務まります。

03

ふだんの使いかた

出かける前 — Mac

仕込んで、画面だけ消す

いつもどおり Mac で Claude Code に作業を頼みます。出かけるときは、 Control ＋ Shift ＋ 電源ボタン。画面が消えても中身は動き続けます。 蓋は開けたままにしてください（閉じると熱がこもります）。 電源につないでおくとなお安心です。

外出先 — iPhone

通知が来たら答えるだけ

「返答待ち」の通知が来たら、ホーム画面のつみきリモートを開いて、 オレンジ枠のタブをタップ。聞かれている内容を読んで 1（はい）か 2（いいえ）を押します。追加の指示を打つのも自由です。

いつでも — iPhone

画像も渡せる

入力欄の左の ＋ から写真を選ぶと、その画像が Mac に置かれ、 置き場所が入力欄に入ります。「ここのエラーを読んで」のように 文章を足して送れば、Claude がその画像を見て答えます。 置いた画像は7日で自動的に消えます。

帰ってから — Mac

続きは同じ画面から

Mac のターミナルで tmux attach -t work1 と打つと、 スマホで見ていたのとまったく同じ画面に戻れます。 スマホと Mac で別々のものを見ているわけではありません。

覚えることは実質2つだけです。 出かけるときは Control＋Shift＋電源ボタン。通知が来たら 1 か 2 を押す。 あとは全部自動で常駐しています。
04

作ったものを見る・持ち出す

ヘッダーの 制作物 を押すと、Mac の ~/制作物 にあるファイルが 新しい順に並びます。選ぶと Safari で実物が開きます。 作ったばかりのアプリを、その場で触って確かめられます。

なぜ iCloud を使わないか

同期を待たなくていい

iCloud は保存から反映まで時間がかかることがあり、「直した直後に見たい」に向きません。 この方式は Mac のファイルを直接読むので、常に最新が出ます。 iOS のファイルアプリで HTML を開くと動かないことがある、という問題も避けられます。

持ち出したいとき

共有ボタンから、どこへでも

Safari で開いたあと 共有 → ファイルに保存を選べば、 そのまま iCloud Drive に入ります。AirDrop でも LINE でも同じです。 持ち出しの仕組みを別に作る必要はありません。

見えるのは ~/制作物 の中だけです。 その外に出ようとするパスは、どんな書き方でも弾くようにしてあります。
05

作業場所を閉じる

閉じたいタブを選んで、右上の ⋯ →「この作業場所を閉じる」。 中で動いているものごと終わるので、確認が一度出ます。

やりかた手順
アプリからタブを選ぶ → 右上の ⋯ → この作業場所を閉じる
Claude の中から/exit と送るとシェルに戻る。さらに exit で閉じる
シェルからexit と送る
Mac からtmux kill-session -t work2
閉じ忘れても害はありません。 待機中の作業場所は何も消費しないので、放っておいて大丈夫です。 Mac を再起動すればすべて消えます。
06

どうやって届いているのか

「外から自宅の Mac が触れる」と聞くと不安になりますが、 インターネットには一切公開していません。順に追うとこうなっています。

iPhone ホーム画面のアプリ ただのWebページです。1.5秒ごとに Mac へ「いまどう？」と聞きに行きます
↓ TAILSCALE 自分の端末だけの内輪ネットワーク Mac と iPhone を直結する専用の通り道（＝身内だけの private な回線）。通信は暗号化され、他人はこの道に入れません
↓ MAC 小さなサーバー（自作・8787番） 自分自身にしか口を開けていないので、この通り道以外からは届きません。合言葉（トークン）も要ります
↓ TMUX 閉じても消えない作業場所 ターミナルの中に作る「畳んでもそのまま残る机」。ここに画面を保管しているので、離れても消えません
↓ CLAUDE CODE 実際に作業しているAI その机の上で動いています。止まったら通知が飛びます

つまり鍵は3重です。①Tailscale の内輪ネットワークに入れる端末でないと辿り着けない ②サーバーは自分自身にしか口を開けていない ③合言葉がないと中身を返さない。 ルーターの設定を開けたりもしていません。

07

通知のこと

iPhone の ntfy というアプリに届きます。鳴るのは AIが返事を待って止まったときだけです。 作業が1つ終わるたびにも鳴らしていた時期がありましたが、 1時間で33通という有様だったのでやめました。

通知に載せているのは「作業場所の名前」と「返答待ち」の2つだけです。 会話の中身・ファイル名・コマンドは外部に一切出していません。 ntfy は外部のサービスなので、そこは意図的に絞ってあります。 ただし購読名を知られると通知は読まれます。人には見せないでください。

09

中身のメモ

あとで自分で触るとき用の覚え書きです。ふだんは読まなくて大丈夫です。

常駐しているもの役割
com.tsumiki.awake画面は消しても Mac を眠らせない（caffeinate -ims）
com.tsumiki.remoteアプリ本体のサーバー（8787番）
com.tsumiki.tailscaled外から届く通り道。管理者権限なしで動く方式

3つとも Mac のログイン時に自動で立ち上がります。状態を見るのはこれです。

launchctl list | grep tsumiki

スマホで読む用のQR（合言葉入り）を出し直すには、これです。

cd ~/制作物/tsumiki-remote && ./bin/qr.sh
  • ソースは ~/制作物/tsumiki-remote/。合言葉などの秘密は ~/.tsumiki-remote/ に分けてあります
  • 眠らせない設定を一時的に解除したいときは launchctl unload ~/Library/LaunchAgents/com.tsumiki.awake.plist
  • このアプリは GitHub Pages では動きません（Mac 上のサーバーが必要なため）。つみきの一覧には載せていません
長時間まわすときは電源につないで、蓋は開けたままで。 閉じた状態（クラムシェル）での連続運用は熱がこもって不利です。 蓋を開けて画面だけ消す今のやり方は、その点で理にかなっています。
