# つみきロック（Mac の幕）

Mac の画面に全画面の幕をかけて、**中（Claude・tmux・つみきリモート）は動かしたまま**、
その場にいる人に画面を使わせないための常駐アプリ。

```
iPhone（つみきリモートの鍵ボタン）──▶ server.js（/api/lock/*）──▶ 127.0.0.1:8797 ──▶ 幕
                           掛ける・外す（どちらも一押し）          掛ける／外す／状態／合言葉
Mac の前：ふだんは Touch ID だけ。**常に待ち受けている＝指を置くだけで外れる**（確認の窓は幕の裏に隠れる）。
         Esc で合言葉の欄に、欄でもう一度 Esc で指紋に戻る。
         Touch ID が通らなかったとき（失敗が3回続く・ロックアウト・使えない）は合言葉の欄（4〜8桁）で外す
```

## 幕の飾り（2026-10-14 本人の選択）
- **空の灯り**：背景が太陽の方角からうっすら橙に明るむ。太陽は画面の縁をたどる（日の出に左の縁の下寄り→上の縁→日の入りに右の縁）。
  灯りの中心は縁の上＝端から差す。日の出の30分前から日の入りの30分後まで。夜は出さない。色はいつも橙
- 左上に日の出・右上に日の入りの時刻、右下にバッテリー（20%以下は警告の色・充電中は稲妻）
- 場所は macOS の位置情報（初回に許可の窓。**幕が外れているときだけ聞く**＝窓が幕の裏に隠れない）。小数2桁で
  `~/.tsumiki-remote/lock-place.json` に残し、取れないときはそれ・無ければ東京。時刻は通信なしで計算（NOAA の簡略式）。
  位置情報には署名の権利（`TsumikiLock.entitlements`）が要る
- **左下に今日の天気**（本人の選択：案2→絵は 10/14 夜に案3）：6〜21時の3時間ごとに 時刻／絵／気温／雨の確率（20%以上）。過ぎた時間は薄く、今の時間は橙の時刻と下線。
  絵は自作の塗り図形（丸と雲だけ・光線なし）を生成りの一色で（晴れ＝丸・夜＝右下が光る三日月・雨＝雲と3本・雪＝雲と3粒・雷＝雲と稲妻・霧＝横線3本）。日の入り後は月の絵。気温は数字だけで中央をそろえ、° は右肩に外付け。行の高さと列の幅は固定＝縦横がずれない。
  左端は日の出と同じ 40、下端はバッテリーと同じ 34。予報は Open-Meteo（鍵なし）に小数2桁の緯度経度だけ渡し、1時間ごとに取り直す（失敗したら5分後・12時間取れなければ天気は消す）。作業の札は天気とぶつからない幅に収め、入らなければ小さくする
- 見本：`--render out.png 1440 900 touch 15:20`（7つ目の時刻で 10/14 東京の空）

## 入っているもの
| もの | 場所 |
|---|---|
| アプリ | `~/Applications/TsumikiLock.app`（`./build.sh` で組み直し） |
| 常駐 | `~/Library/LaunchAgents/com.tsumiki.lock.plist`（KeepAlive・Aqua） |
| 掛け外しの鍵 | `~/.tsumiki-remote/lock-key`（0600・server.js と共有） |
| 幕の状態 | `~/.tsumiki-remote/lock-state.json`（落ちて起きたとき掛け直すため） |
| 合言葉 | 鍵束（キーチェーン）`com.tsumiki.lock` / `pin`。**値ではなく塩＋PBKDF2 だけ** |
| パスキー | `~/.tsumiki-remote/passkeys.json`（公開鍵だけ） |
| 記録 | `~/.tsumiki-remote/lock.log` |

組み直したら `launchctl kickstart -k gui/501/com.tsumiki.lock`。

## 守り
- 幕の高さは常にいちばん上（CGShieldingWindowLevel）。Touch ID の確認の窓（coreautha・1000）は幕の裏に隠れたまま待ち受ける
  （常に待ち受けるので、窓を見せるために幕を下げると、ほぼずっと下がったままになるため）
- 幕が前にいるあいだは ⌘Tab・強制終了・Dock・メニュー・ログアウトを止める（presentationOptions）。
  ただし Touch ID の待ち受け中は確認の窓が前にいるので、これが効かない恐れがある（下の弱点）
- ほかのアプリが前に出たら（Touch ID の確認中でも）確認を打ち切って前に戻る。2秒ごとにも前に出し直す。
  その記録は同じアプリなら10秒に1行。待ち受けは60秒ごとに張り直し、終わってから1秒は次を始めない
- 合言葉の欄では数字・⌫・Enter・Esc 以外のキーは捨てる。空の Enter は何もしない
- 待機の画面は Touch ID だけ。板が隠れているあいだは数字を受けない。外すか掛け直すと板は隠れる。
  Esc で確認をやめた（userCancel）ときも欄を出す。こちらから打ち切った・ほかのアプリに移ったときは出さない。
  欄を出しているあいだは待ち受けない（キーを合言葉に使うため）。欄で Esc を押すと指紋に戻る
  （Esc の押し間違い・画面が眠って確認が打ち切られた・鍵束が読めない、のどれでも Touch ID に戻れる）
- 合言葉は最後まで打っても勝手には確かめない（丸は打った数だけ・打つ前は線だけ＝桁数を見せない）
- 合言葉を5回まちがえると 30秒→60秒→…（上限10分）待たせる。数えは状態ファイルに残る
- 鍵束は専用のキューでしか触らない（「許可しますか」で止まっても、幕と iPhone からの解除は動く）。
  幕の上の合言葉は、起動時と掛けるときに読んでおいた写し（塩と鍵）と比べる＝幕の上では鍵束を読まない。
  写しが無いとき（鍵束が読めない）は「まちがい」として数えない。確かめは5秒で必ず戻る
- 合言葉の決め直しは書き換え（Update）→無ければ追加。先に消さない（足せなかったときに「合言葉なし」で掛かるのを防ぐ）
- 幕で指紋が合わない・Touch ID がロックされた・合言葉を間違えたら iPhone に知らせる（つみきリモートと同じ ntfy の話題）。
  1回の掛けにつき5分に1回まで（黙っていた分は5分たったら1通にまとめる）。送るのは決まり文句だけ。本人の指の失敗でも鳴る。
  夜（22時〜8時）は鳴らさず数えるだけで、朝8時を過ぎたら「夜のあいだに◯◯ 何回」を1通にまとめる（数えはメモリだけ）
- 幕には作業の題名を出さない（お客様の名前が入ることがある）。状態ごとの数だけ
- 127.0.0.1 の口は鍵（x-lock-key）を先に確かめ、本文は 0〜64KB だけ読む。5秒で切る
- 状態ファイルがあるのに読めないときは「掛かっている」として起きる
- 掛けるのも外すのも iPhone からは一押し（2026-10-13 本人の選択。iOS のパスキーは毎回「サインイン」の
  シートをはさみ Web から消せないため、Face ID をやめた。守りは iPhone のロックとつみきリモートの合言葉）。
  パスキーは合言葉の決め直しにだけ使う
- 合言葉を決めないと掛けられない（Touch ID が通らないとき Mac の前で外せなくなるため）。
  つみきリモートの帯の鍵は ↻ の隣に置かない（外すのも一押しなので、押し間違いで外から外れるのを防ぐ）
- 最初のパスキー登録と合言葉は Face ID なしで決められる（幕のアプリが動いていて、幕が外れているときだけ）。
  決め直しは登録済みのパスキーが要る。passkeys.json が壊れていたら何も通さない

## わかっている弱点
- **これは macOS のログインの鍵ではない。** 電源の長押しで再起動されれば幕は消える
  （再起動後は macOS のログイン画面が守る。そのあとログインすると幕が掛け直される）
- 強制終了などで幕のアプリを落とされると、launchd が起こし直すまで約2秒は素通しになる（未実測）
- ミッションコントロール・4本指・ホットコーナー・Siri・VoiceOver を全部は試していない。
  別のアプリが前に出れば戻す作りだが、前に出ない形で裏が見える道があれば防げない
- 前にいる人が合言葉をわざと間違えて待たせたり、Touch ID をわざと失敗させたりはできる（外から iPhone で外せる）
- iPhone からは一押しで外せる＝つみきリモートの合言葉（?t=）を持つ人なら外せる（本人が受け入れた前提）。
  パスキー（合言葉の決め直しに使う）は認証器の証明を取っていない（attestation:none）
- Touch ID の確認中に、勝手に前に出てくるアプリがあると確認が打ち切られる（すぐ張り直す）
- **確認の窓が幕の裏に隠れたまま指を受けるか・Esc が届くかは、実機で確かめていない**（幕の上の Esc は届かなくても板にする）
- 待ち受け中（ほぼ常に）は確認の窓が前にいるので、⌘Tab や ⌘⌥Esc が効く恐れがある。ほかのアプリが前に出れば
  すぐ戻すが、強制終了の窓（loginwindow）で知らせが来るかは未確認
- 続けて失敗するエラーは、次を始めるまでの間を 2→4→…→60秒に広げる。記録は種類が変わったときだけ
- 状態ファイルが壊れて「掛かっている」で起きたとき、合言葉が鍵束に無ければ、外す道は Touch ID（欄なら Esc で戻る）と iPhone だけ
- パスキーを iPhone から消したら、Mac で `~/.tsumiki-remote/passkeys.json` を消して登録し直す

## 試験のしかた（本番の状態・鍵束に触らない）
環境変数で置き場と口と鍵束の名前を変える。`TSUMIKI_LOCK_AUTOUNLOCK=秒` で勝手に外れる。
`/try`（キーを打たずにボタンと同じ道を通す）は鍵束の名前が本番以外のときだけ開く。
```
open -n --env TSUMIKI_LOCK_CONF=<別の置き場> --env TSUMIKI_LOCK_PORT=8798 \
  --env TSUMIKI_LOCK_KC=com.tsumiki.lock.test --env TSUMIKI_LOCK_AUTOUNLOCK=30 TsumikiLock.app
TsumikiLock --render out.png 1440 900    # 幕の見た目を画像に（架空の席）
```
⚠️ tmux の中から直接起動すると画面（WindowServer）の外になり、幕が出ない。`open` か launchd で起動する。
