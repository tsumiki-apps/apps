Rare UI 移植見本

rareui.com（MIT・React + Motion）の考え方を、つみきの単一HTML／素のJSに写したもの。色は「つみきの紙」に置き換え済み。

1. ぐにゃりタブ

えらんだ札だけが群れから離れ、離れぎわに「首」が伸びて切れる。ぼかしフィルタではなくSVGの曲線で首を描くので、にじまない・文字が汚れない・軽い。

元：Gooey nav ／ 首＝2本の二次ベジェ、すき間が「間隔×0.22」を超えた時点で首は消える

2. その場で確かめる削除

confirm() の代わり。ゴミ箱のフタが開いて、缶が身をかがめ、右に ✓ と ✕ が出る。画面が飛ばないので、何を消そうとしているか見えたまま決められる。

元：Delete button ／ フタは 3px 6px を軸に −35°、缶の胴は d 属性を 6→13.5 で書き換え

3. くるくる回る数字

合計や件数が変わったとき、桁がドラムのように回る。上下をぼかしマスクで溶かすので、止まっている桁はくっきり、回っている桁だけ流れて見える。

元：Animated counter ／ マスクは 22%〜78% が不透明、その外を段階的に抜く

4. 割れる時間入力

ふだんは1つのかたまり。えんぴつを押すと3つに割れて角が丸くなり、割れる勢いで中身が少し横に振れる。「いま編集中」が形でわかる。

元：Duration picker ／ すき間ばねの速度を ±3px の横ゆれに写している（アイコンの変形は簡略化＝入れ替え）

5. プロダクトキー入力

1文字ずつ下から転がり込む。そろったら緑の枠が描かれ、ちがえば赤くふるえる。TSUMIKI と打つと成功、それ以外は失敗。

元：OTP input ／ 成功の枠は SVG の stroke-dashoffset で「描かれる」

6. 表面のトークン

Rare UI の「持ち上がり」は影が3枚重ね。0.5px の輪郭 + 3px のやわらかい影 + 上端の白いハイライト。つみきの紙色にそのまま効く。角は squircle（対応ブラウザのみ）。

--lift（3枚重ねの影） corner-shape:squircle ばね stiffness 200 / damping 28

元：全コンポーネント共通の SURFACE / GLYPH / LIFT 定数
