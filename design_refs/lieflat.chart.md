- **出典**: https://github.com/larashero3-dotcom/lieflat-charts （★4,970・moxt.ai 制作）
- **ライセンス**: ⚠️ **PolyForm Noncommercial 1.0.0 — 非商用のみ。**
  `~/tsumiki-tools`（有料配布）・受託（Kouban/Teppari）・つみきサイトには**使えない**。
  だから**ファイルもコードも持ち込んでいない。このメモは考え方を日本語で書き直したもの**。
- **取得日**: 2026-09-08 ／ 調査 → `~/つみき出力/道具としらべ/lieflat-charts_調査と採用可否_2026-09-08.md`
- **中身**: AIエージェント向けの可視化スキル。図型カタログ63枚＋全1ページのレポート雛形12種。
- **これは refero-styles の採取物ではない。** refero は「配色・角丸・影の体系」、
  rareui は「動きの作り方」、こちらは「**データを図にするときの作法**」。
  したがって `*.design.md` ではなく `*.chart.md` に置いた。

> **向こうは PC・印刷前提**（メディアクエリがほぼ無い／レポートは `width:1080px` 定尺）。
> **つみきは8幅すべて**（320〜1920）。**レイアウトの数値は借りない。借りるのは考え方だけ。**

## 1. 色 — 明度がデータ

いちばん大事なもの＝いちばん濃い。これだけ決めておくと「何色にするか」で悩まなくなる。

- 系列が複数あるとき、**濃さの段（ladder）を重要度の順に配る**。並び順で適当に取らない。
- **塗りはベタ。** 光らせない・グラデにしない・影を落とさない。質感は濃さの差と形で出す。
  例外は1つだけ：**重なりの濃さそのものが数（密度）を表しているとき**。それは装飾ではなくデータ。
- 色を使うなら**1つの成果物につき1系統だけ**。1枚のページに2つの配色を混ぜない。
- 類目が **6を超えたら彩色をやめて濃淡に戻す**。7色目からは誰も見分けられない。

**色そのものの正本は `~/制作物/DESIGN.md`。このメモは色を1つも足さない。**
DESIGN.md の語彙に置き換えると：

| 役 | 使う変数 |
|---|---|
| いちばん濃い（主役の系列） | `--ink` |
| 中くらい | `--ink-mid` / `--sub` |
| 薄い（脇役・比較対象） | `--muted` |
| 目盛り・罫線 | `--line` / `--hair` |
| 面の下地 | `--card` / `--surface-2` |
| 1点だけ立てたいとき | `--accent`（**1画面に1つまで**・DESIGN.md の決まり） |
| 費目・分類の塗り分け | `--pigment-1〜6`（7色目を作らない）。**顔料そのものを塗りの地にしない**、`-wash` に敷いて文字は墨 |

- 純白 `#ffffff` と純黒 `#000000` は使わない（DESIGN.md）。図の中でも同じ。
- 凡例の四角・線・細い印のように**文字を乗せない場所**なら顔料をそのまま使ってよい。
- 描き終えたら2つとも通す：
  `python3 design_check.py <HTML>`（コントラスト・純白純黒・8幅）と
  `python3 color_leak.py <HTML>`（色板からの漏れ）。

## 2. 図のまわり（四点セット）

図だけ置かない。**必ずこの4つを上から順に**。

1. **見出し** … **結論を書く。図型名を書かない。**
   ✗「棒グラフ」「月別売上」 ／ ○「伸びたのは火曜だけだった」
2. **副題** … 凡例・単位・期間を `・` 区切りで1行。**読む人はコードを読まない。ここだけ読む。**
   例: 「1点＝1件 ・ 2026年4〜6月 ・ 白丸は土日」
3. **図**
4. **出典行** … 小さく・字間を広げて。「何のデータか」を必ず書く。

副題を書けないなら、その図はまだ何を言いたいか決まっていない。

## 3. 誠実な符号化（ここを破ると図が嘘になる）

- **棒の軸を切らない。** 棒の約束は「長さ ∝ 数値」。途中を省いたら約束違反。
  極端な値があるときの正しい手は3つ。
  ① そのまま突き抜けさせる（いちばん正直）
  ② 全体図＋その部分だけの拡大図を並べる
  ③ 棒を破く（軸は破かない・「入りきらない」と明記する）
- **面積で表すときは半径に `Math.sqrt(値)`。** 値をそのまま半径にすると、
  2倍のはずが見た目4倍になる。
- **最小の文字サイズに下限を決める。** 入らない情報は**縮めずに hover / タップに逃がす**。
  つみきは指で触るので、**hover だけに逃がさない**。タップでも出るようにする。
- 隣り合うラベルは**最小の間隔を強制**する。重なったら片方を間引くか、引き出し線で逃がす。
- 丸めて合計が100にならないとき（49.0+27.4+13.9+5.0+3.2 → 98）は、
  **「四捨五入で2件ぶん落ちています」と脚注に書く**。数を足して100に見せない。

## 4. データが少ない図が貧相に見える理由

**データが少ないからではなく、データでない構造物（＝家具）が無いから。**

家具の例：帳簿の罫線 ／ 破線のガイド ／ 外周の目盛りヒゲ ／ 10単位ごとの縦線 ／
旁注の引き出し線 ／ 期間の区切り ／ 基準線（平均・目標）。

- **密度の予算は家具に使う。** データ層は薄いまま正直に。
- 「棒が3本＋下に線1本」だけの図は、何をどう塗っても寒々しい。
- もうひとつの手が**単位に割り戻す**こと。「42%」を「100個の点のうち42個」に開く。
  ただし**実在しない個体をでっち上げない**。割合の合計が100になるときだけ使える。

## 5. 動き

**`~/制作物/tn.js` に実装済み。**（`python3 inject_tn.py <HTML>` で入る）

- `TN.reveal(id, fn)` … **見えたら描く・押したらもう一度**。
  再生前にタイマーを全部消すので連打しても積み上がらない。
  `prefers-reduced-motion` のときはアニメ抜きでその場で1回描く（`ctx.reduced` で分岐）。
  画面に寸法が無いところ（スクショ用ヘッドレス・PDF書き出し）では
  IntersectionObserver が発火しないので、1.2秒後に描く保険つき。
- **時間の正本は `DESIGN.md` の Motion。** `quick:120ms` / `normal:200ms` /
  `cubic-bezier(0.2, 0, 0, 1)`、**300ms を超えるものは作らない**。
  向こうの入場 900ms・棒1本ごと80〜130msずらしは**つみきでは長すぎる。採らない。**
  ずらすなら**全部足して 300ms に収まる範囲**で（棒24本なら 1本 4ms ＋ 本体200ms）。
- 入場は速く入って速く止まる。跳ね返らせない。
- **動きのために構造を変えない。** ある効果を入れるためにレイアウトを作り直すなら、その効果は要らない。

## 6. デモ・架空データの乱数

**`Math.random()` を使わない。`TN.rnd(i, k)` を使う。**（`~/制作物/tn.js`）

リロードのたびに形が変わると、スクショも録画も「前と同じか」の見比べも全部あてにならない。
つみきは**架空データの複製から画面を撮る**運用（お返事カード・IG投稿・せんや）なので、ここは死活。

> 本家の式 `((i*73856093)^(k*19349663))%1000/1000` は **k=0 のとき 0.000/0.093/0.186… と
> 等差の直線になる**（実測）。既定の k=0 でいちばん使うのに散らばらないので、
> `tn.js` では別のかき混ぜ方に替えてある。

## 7. 図の枚数は「独立した結論の数」で決める

データの列の数でも、テンプレートの数でもない。

| 頼まれかた | 既定の枚数 |
|---|---|
| 1つの問い・1つの指標 | **1枚**（いちばん強い1枚だけ） |
| はっきりした結論が2〜3つ | 2〜3枚（1枚＝1結論） |
| 記事・報告・ふりかえり一式 | 4〜6枚（総覧・構成・比較・変化で役を分ける） |

- **1ページ6枚が上限。** 超えるなら章で分ける。
- 同じ結論を言う図が2枚あったら、**読む場面に合うほうだけ残す**。
- 1ページの中で**同じ輪郭を繰り返さない**（丸が6個並ぶページにしない）。

## 8. 断るもの（代替とセットで断る）

「何でもやります」より、**理由と代わりを出して断るほう**が信用される。

| 頼まれたこと | 代わりに出すもの |
|---|---|
| 軸を切った棒グラフ | 突き抜け／拡大の小図／棒を破く の3案 |
| 光らせる・ガラス風・3D | いまの見た目のまま。質感は濃さの差で出す |
| 単一の系列を多色相で | 濃淡1系統に戻す |
| 類目7つ以上で彩色 | 濃淡に戻す |
| 飾りだけの線や点に hover | 断る（中身の無いものを触れるようにするのは嘘） |
| 3ノードで力学グラフ | もっと単純な図に落として理由を言う |

**「その線1本の裏に、データが1件あるか？」**——無ければ触れるようにしない。
50本を超えて両端に注記が置けないなら、逆に**必ず**触れるようにする（でないと雰囲気の絵になる）。

## 9. つみきに合わせて必ず変えるところ

| 向こう | つみきでは |
|---|---|
| メディアクエリほぼ無し・`1fr 1fr` 固定・`width:1080px` | **8幅すべて**（320/375/390/430/768/1024/1440/1920）。区切りは600と900の2本 |
| Inter ＋ Noto Sans SC（簡体字） | 日本語の字形が違う。**本文はつみきの既存書体**、ブランドは Zen Maru Gothic |
| hover 前提の情報 | **タップでも出す**（44px以上） |
| ECharts / Chart.js を CDN から | **単一HTMLの自足を優先**。素の SVG で描けるものは素の SVG で |
| Google Fonts を読みに行く | オフラインで開けなくなる。使うなら承知のうえで |
| 全部入りの `<style>` を丸ごと | 色は `--ink/--sub/--line/--accent` から取る。**新しい変数を発明しない** |
