# refero styles をつみきに写す

refero styles の公開ページには、そのサイトの配色・余白・角丸・影が
`designSystem` という構造化JSON（約13KB）で丸ごと埋まっている。
これを**つみきの既存CSS変数に流し込む**のがこのスキル。

## 前提（蒸し返さない）

- **MCPは使わない。** 公式MCP（有料）も非公式MCP（npm）も入れていない。
  **「MCPを持っている」と言わないこと。** 持っていない。
- 道具は `~/制作物/refero_tokens.py` だけ。
- 参照メモの置き場は `~/制作物/design_refs/<名前>.design.md`。
- 根拠: `~/つみき出力/refero-styles調査結果.md`（2026-09-04 実測）
- 選べるブランド50件: `~/つみき出力/refero-styles一覧.md`

## 手順

### 0. 先に「手元にたまっているメモ」を見る

`~/制作物/design_refs/*.design.md` が**これまで写した見本の書庫**。
新しく取りに行く前に、まずここを一覧する。

```bash
ls ~/制作物/design_refs/*.design.md
head -8 ~/制作物/design_refs/*.design.md
```

- 近いものが既にあれば**取りに行かない**。そのメモの数値をそのまま使う（通信ゼロ・robots に触れない）。
- 見た目の相談をされたとき、refero の話が出ていなくても、
  ここのメモは**そのまま設計の下敷きとして使ってよい**（配色の考え方・角丸・影・余白）。
- 1本増えるたびに書庫が厚くなる。**取ってきたら必ず `--memo` で残す**。

### 1. URLを受け取る

`https://styles.refero.design/style/<UUID>` の形1本だけ。
ブランド名だけ言われたら、まず `~/つみき出力/refero-styles一覧.md` から
UUIDを引く。一覧に無ければ**推測でUUIDを組み立てず**、
「一覧に無いのでURLをください」と聞く。

### 2. 取得して変換する

```bash
cd ~/制作物
python3 refero_tokens.py "https://styles.refero.design/style/<UUID>" \
  --name <呼び名> --memo --out /tmp/refero.css
```

- 標準エラーに**コントラストの実測値**が出る。これは報告にそのまま使う。
- `--memo` で `design_refs/<呼び名>.design.md` が出る。
  ここには **出典URL・取得日** が入る。**消さない。**
- 取得に失敗したら、そこで止める。**「取れなかった」と正直に書く。**
  推測で色を作って埋めない。

### 3. 参照メモの日本語要約を埋める

`design_refs/<呼び名>.design.md` の「## 日本語要約（Do / Don't）」は
スクリプトでは埋められないので **（未記入）** で出る。
上の原文 Do/Don't を読んで日本語に訳して差し替える。
訳さないまま終えるなら「未記入のまま」と報告に書く。

### 4. 対象HTMLに当てる

- **必ず複製で作業する。** `cp app.html app_テスト.html` のように
  ファイル名に `_テスト` を付ける。本番HTMLを直接いじらない。
- 対象HTMLの `:root{...}` を、出力された `:root{...}` で**置き換える**。
  出力に無い変数（`--good` `--warn` `--shadow` など）は
  **既存の値をそのまま残す**。消さない。
- ダークの上書きブロックも一緒に入れる。
  既に `@media (prefers-color-scheme: dark)` があるなら、その中身を差し替える。

### 5. 8幅で検証する

**320 / 375 / 390 / 430 / 768 / 1024 / 1440 / 1920** の全部。
確認は**幅375pxの iframe で実測**する（`--window-size` は嘘をつく）。
ライト・ダーク両方を見る。

幅を変えた直後は**1秒待ってから測る**。待たないと前の幅の値が返る（実際に踏んだ）。

必ず測る箇所（`getComputedStyle` で実測。トークンの計算値ではなく**画面の実物**を測る）:

| 見るもの | 目安 |
|---|---|
| 本文・補助文字・小さいラベル | 4.5:1 以上 |
| **塗りボタンの文字**（`background:var(--accent)` の上） | 4.5:1 以上 |
| 選択中のチップ・タブ（`--accent-2` が乗る） | 4.5:1 以上 |
| 横スクロール | `document.documentElement.scrollWidth > innerWidth` が false |
| 入力欄の font-size | 16px 以上 |

**塗りボタンの文字色に気をつける。** アプリ側が `color:#fff` を直書きしていることがある。
明るいブランド色をダークで使うと、白文字が 4.5 に届かないことがある
（実例: Notion の青 `#0080f3` に白は 3.90:1）。
`refero_tokens.py` は「白でよい／濃い文字にすること／塗りに使わないこと」を
`/* ! ライト: ... */` `/* ! ダーク: ... */` の行で必ず教えるので、**そこを読んで直す**。
直すときは既存の変数だけで書く（`color:var(--paper)` など）。新しい変数を足さない。

### 6. 報告する

1. 何を変更（作った・触ったファイル一覧）
2. どう変更（参照した refero URL、どの色をどの変数に写したか、未割当だった色）
3. どう動作したか（**8幅それぞれ OK / NG**、コントラストの実測値）

失敗・未検証・スキップは正直に書く。「対応しました」で塗りつぶさない。

## 守ること（守れていなければ不合格）

### robots.txt

styles.refero.design の robots.txt は
`ClaudeBot` `anthropic-ai` `GPTBot` など**AIクローラーを名指しで全面 Disallow**。
`/api/` も Disallow。

- **一括クロール・全カタログのミラーを作らない。** 1,290本を落とす、はやらない。
- 取りに行くのは **人が選んだURLを1本ずつ**だけ。
  `refero_tokens.py` に一括取得モードは無い。**足さないこと。**
- **`/api/` は叩かない。**

### フォント

refero が指定するのは Denton / SF Pro / Geist のような欧文で、**日本語グリフが無い**。

- **本文フォントに採用しない。**
- **ブランド書体 Zen Maru Gothic を上書きしない。**
  `refero_tokens.py` は `--sans` `--serif` `--brand-font` を出力しない。
- 借りてよいのは **サイズ階層・ウェイト・行間・字間** だけ。
- どうしても欧文が要る箇所（数字・英字ラベル）は、参照メモの `substitute` を見て
  Google Fonts で置換する。

### つみきの共通ルール

- つみきロゴは公式SVGを**座標ごとコピー**する。
  正本 = `~/制作物/index.html` の `<svg class="mark" viewBox="0 0 100 100">`。
  簡易キューブの自作・絵文字代用・平面化・`fill="none"` はしない。
- 8幅すべてで作る = **320 / 375 / 390 / 430 / 768 / 1024 / 1440 / 1920**。
  ブレイクポイントは **600 と 900 の2本だけ**。固定px幅を作らない。
  入力欄 16px 以上、タップ 44px、`100dvh`、表は `overflow-x:auto`。
- 確認は**幅375pxの iframe で実測**する（`--window-size` は嘘をつく）。
- 本文コントラストは **4.5:1 以上を実測**する。
  refero の見た目より**読みやすさを優先**する
  （欧文の細字前提の淡い配色が多く、日本語だと読みにくくなる）。
  `refero_tokens.py` は 4.5:1 を満たすまで自動で色を沈める。
  直した記録はCSSのコメントと参照メモに残るので、報告にも書く。
- 動作確認は**複製**で行う。**実データに書き込まない**
  （実画面のボタン押下・input発火・フォーム送信は save() → クラウド push を呼ぶ）。
- ブラウザペインに撃つJSは1行目にガードを置く:
  `if(!location.href.includes('_テスト')||sb) return 'ABORT';`
- **ロゴ・画像・フォント本体はコピーしない。** 借りるのは数値と方針だけ。
- commit 前に、追加・変更したファイル全部を**実在の氏名・電話・住所で grep して0件確認**する。

### 嘘をつかない

- **MCPを持っていると言わない。** 入れていない。
- 取れなかったら**取れなかったと書く**。色を捏造して埋めない。
- 検証していない幅を「OK」と書かない。見ていないなら「未検証」と書く。

## 対応表（新しい変数名を発明しない）

`~/制作物` の87本のHTMLを実測して決めた既存の語彙。**表に無いものは出力しない。**

| つみきの変数 | 入れるもの |
|---|---|
| `--paper` / `--bg` | `surfaces` level 0 |
| `--card` / `--surface` | `surfaces` level 1 |
| `--surface-2` | `surfaces` level 2 |
| `--ink` | `colors` の role が「Primary text」相当 |
| `--ink-mid` / `--ink-soft` / `--sub` / `--muted` | role が「Body text」「Muted」「helper」相当 |
| `--line` / `--line-2` / `--hair` | role が「borders」「dividers」相当（**有彩色の罫線は採らない**） |
| `--accent` / `--accent-2` | `colors` の `group:"brand"` |
| `--accent-wash` / `--accent-soft` | accent を薄めたもの（スクリプトが算出） |
| `--good` / `--warn`（＋`-wash`） | refero側に無いことが多い。**無ければ既存値をそのまま残す** |
| `--shadow` | `elevation` のうち element が Card のもの |
| `--radius` | `spacing.radius.cards` |

判定できなかった色は**捨てずにコメントで残る**（`/* 未割当: #xxxxxx Name — role */`）。
報告にもそのまま載せる。

## そのままは使えないもの

1. **フォント** — 上記のとおり。本文には使わない。
2. **色のコントラスト** — 欧文の細いウェイト前提の淡い配色。日本語＋16px だと読みにくい。
   スクリプトが 4.5:1 まで沈めるが、当てたあと**目で見て**判断する。
3. **レイアウトの数値** — `pageMaxWidth: 1440px` などはPC前提。
   **つみきの8幅ルールが優先**。参照メモには残すが、そのまま使わない。
4. **もとが dark 基調のサイト** — `:root`（ライト）のほうが導出値になる。
   ライト側は必ず目視する。
