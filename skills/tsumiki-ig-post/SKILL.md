# つみきIG投稿（画像4枚＋リール動画＋キャプション）

正本の型 → `~/ObsidianVault/Playbooks/app-post-and-reel-format.md` を**必ず先に読む**。
道具 → `~/つみき出力/Instagram運用/` の `reelbase.py` `make_posts.py` `render_*.py` `mp4に書き出す.swift`
出す先 → `~/Library/Mobile Documents/com~apple~CloudDocs/Kodai/00_Tsumiki/14_Instagram投稿/`（`画像/` `リール動画/`）

## 進め方

1. **どのアプリか確認**する。決まっていなければ番号つきで聞く（A層 §2 のとおり選択UIは使わない）。
2. **テスト複製を作る**（本番HTMLは絶対に触らない）
   - `const sb = null` に置換 → `createClient` の残りを grep で 0 件確認
   - ライセンスゲートがあれば `<!-- tsumiki-license-gate -->` の範囲を削除
   - 通信で動くアプリは `window.rpc` を差し替えて**にせのサーバー応答**＋**架空データ**
   - 撮影は使い捨ての Chrome プロファイル（`--user-data-dir`）
3. **画面を3〜5枚撮る**
   - `<iframe 402×874>` に入れて ウィンドウ500×900・dsf3 → 1206×2622 で切り出す
   - `?shot=N` で スクロール位置・タブ・シートを切り替える
   - PC用は 1440×900・dsf2 で1枚
4. **投稿画像4枚**：`make_posts.py <アプリ名> <画面1> <画面2> <画面3> <PC> <出力先>`
5. **リール**：`render_*.py` をひな形に、帯の自動検出→組み上がり→白い丸の操作→mp4
   - ⚠️ **解説テロップ（下の白い帯）は 2026-09-06 に試して不採用**。既定では**入れない**。
     頼まれたときだけ `Phone(..., telop=True)` で復活させる
   - **30秒以上**にする（操作を増やすか、組み上がり1回＋操作2周）
   - 書き出したmp4は**必ず読み返して**長さ・大きさ・fpsを実測する
6. **出す前に** `swift ~/制作物/shots_ocr.swift "実名,店名" <画像...>` で焼かれた文字を読む。
   実データを使った場合は「写真とメモ文は本物」と本人に明示する。
7. **キャプション**を下の「キャプション」の型で書き、`caption_check.py` を通す。

## 決まっている値（変えない）

- 1080×1350（4:5）／背景＝つみき布（暗い版・alpha 0.075）／端末は画面高さ1000・上から150px・中央
- **9:16（1080×1920）が要るときは `REEL_916=1` を立てて同じスクリプトを回す**（2026-09-08 に6本作成）。
  端末の大きさは4:5と同じ・上余白120・ロゴ中心y=1242 で、**下に文字を置ける余白206px**（y=1294〜1500）が空く。
  リールのキャプションUIは下から約420px。文字は動画に焼き込まず、場所だけ空ける。
  台本＝`~/つみき出力/Instagram運用/リール動画/9x16で一括で作る.sh`、実測＝`動画を測る.swift`。
  上余白や端末の大きさは `REEL_PHONE_Y` `REEL_SCREEN_H` で変えられる（B案=60／C案=90+900）
- 白い丸：半径74・塗り `rgba(232,231,227,.82)`・押すと26%縮む＋波紋・移動1.25秒
- 端末の上余白は **150**（下に公式ロゴを置く形が既定）
- テロップを入れる指示があったときだけ：帯は左右余白60・高さ120・角丸26・下余白60・`#FAF9F6`／
  ロゴ74px／文字はヒラギノ丸ゴ ProN W4を46pxから自動縮小／端末の上余白は60に詰める
- 端末は**回さない**。2台は「左を上・右を下」に段違いで置く
- **Appleの Product Bezels は使わない**（ライセンス2.B。つみきのアプリはApple以外のOSでも動くWebアプリ）

## キャプション（投稿の文章）

型と理由の正本 → `~/つみき出力/Instagram運用/つみきIG_キャプションのテンプレ_2026-09-11.md`（型A〜E・言わない言葉・タグ）
実例（2026-09-11 に9件へ入れた最終版）→ 同じフォルダの `つみきIG_キャプション_入れた文面_2026-09-11.md`
新しく書いた文面の置き場 → `python3 ~/制作物/tsumiki_out.py Instagram運用 "<アプリ名>_キャプション_<日付>.md"`

### 形（アプリ紹介の投稿）

```
〈問いかけ〉 〈絵文字1つ〉                     ← 25字前後・「！」なし

〈場面を2〜3行〉                                ← 断定しない（〜かもしれません／〜だと思っています）

「〈アプリ名〉」は、〈何をする〉アプリです。
〈絵文字〉 1枚目｜〈1枚目の画面でわかること〉
〈絵文字〉 2枚目｜〈2枚目〉
🎬 3枚目｜〈操作の流れ〉を動画で               ← 実際の枚数に合わせて行を増減する

〈型A：線引き1行＋逃げ道1行 ／ 型B：仕事への橋3行〉

つみき｜オーダーメイドのアプリ制作
毎月かならず出てくる、大切なんだけど時間がかかっている仕事を、短時間で終わらせられるようにするアプリをお作りしています。
💬 ご相談とお見積りは無料です。料金の目安と、これまでに作ったアプリはプロフィールのリンクから。

#オーダーメイドアプリ #川崎 #〈業種・場面〉 #〈〃〉 #〈〃〉
```

- **型A**＝お仕事のアプリ（打刻・てっぱりボードなど）。逃げ道の例「今の表で回っているなら、それが一番です。」
- **型B**＝暮らしのアプリ（クレカ明細・ごはん日記など）。橋は固定：
  「〈誰〉のために作ったアプリです。／人を道具に合わせるのではなく、道具のほうを人に合わせる。／お店や会社の「うちのやり方」にも、同じ考え方でお作りしています。」
- **型D リール**・**型E ピン留め**はテンプレの §4・§5
- ⚠️ **枚ごとの見出しは、実際に出した画像を見て書く**。2026-09-06 の投稿は「ヒーロー → 段違い2台 → リール動画」の3枚組で、テンプレが想定した4枚と違った
- 絵文字は**1件4〜5個まで**（1行目の終わり・枚ごとの見出し・締めの 💬）。本文の途中には入れない（本人の指示 2026-09-11「適度に多すぎない程度に」）
- タグは**5個まで**（Instagram の上限・2025年12月から）
- 言わない：小さな／ちょっとした／事務仕事／タップだけで終わる／AIで安く／勤務先の名前／お客様の名前／実測のない数字（◯分短縮）
- 漢字は普通に使う（今・一番・他の・後で）
- 画面が見本データなら一言添える（「画面の金額は見本です」）。実データを使った投稿では書かない
- 検査（✗ が1件でもあると終了コード1）：

      python3 ~/.claude/skills/tsumiki-ig-post/caption_check.py <文面.md または .txt> --names "実名,店名"

### Instagram に入れる（頼まれたときだけ。公開物への書き込み）

- Claude in Chrome で投稿を開く → 「その他のオプション」→ **文字が「編集」と完全に一致するボタン**を押す。
  ⚠️ **メニューの一番上は「削除」**。座標では押さない
- キャプション欄（`[role=dialog] [contenteditable=true]`）が**空であること**を確かめてから、paste イベントで貼る。
  欄の `innerText` が元の文面と**完全一致しなければ止める**（スクリプトの中で throw して、後の操作に進ませない）
- 「完了」は**マウスのクリック**で押し、**5秒待ってから**再読み込みして、本文に1行目が出ているか確かめる
  - ⚠️ JS の click で「完了」を押してすぐ再読み込みしたら、保存されなかった（2026-09-11）
  - ⚠️ ページを開いた直後は、メニューが開かないことがある → 最大3回やり直す
- 最後にプロフィールを開き、投稿数と並びが変わっていないことを確かめる
- 読み取りAPI（`/api/v1/...`）は 429 を返すことがある。中身の確認は画面表示で読めば足りる
