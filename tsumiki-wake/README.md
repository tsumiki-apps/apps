# つみきウェイク（Mac を眠らせない・メニューバー）

メニューバーに常駐して、Mac を眠らせないアプリ。アイコンは `Icon.swift` でコードから描く（メニューバーは1色のテンプレートで、明るい/暗いメニューバーに自動で合う）。

| アイコン | 状態 |
|---|---|
| 線だけの積み木 | 眠れる（何もしていない） |
| 塗った積み木 | 起きている（画面は消えてよい） |
| 塗った積み木＋光の線 | 起きている・画面も |

| 操作 | 中身 |
|---|---|
| 左クリック | メニュー |
| 右クリック | すぐ開始／停止 |
| ⌃⌥⌘W | 開始／停止（設定で外せる） |

- メニュー：状態（残り時間と終わる時刻）・開始／停止・時間（無期限・15分〜8時間・時刻まで）・延長（15分・1時間）・画面も・設定・記録・閉じる
- 設定：ログイン時に起動・起動時に開始（既定 ON）・復帰時に開始（既定 ON）・電池で停止（なし／10%／20%／30%・既定 10%）・開始の長さ（右クリック・⌃⌥⌘W・起動時に使う。既定は無期限）・ショートカット（ほかのアプリと重なって登録できないときは、そう出る）
- 復帰時に開始：手で止めていても、復帰したら始める。ただし時間切れ・電池で止まったときと、電池が低いままのときは始めない
- 電池で停止：電池で動いていて、残りが決めた％**になった瞬間**に止めて通知する。起動した時点ですでに低い・低いまま手で始め直した・上限を後から変えた、のどれも、すぐには止めない（電源につないで外したら、また「なった瞬間」になる）
- 記録：通算の時間・回数・最長。10秒ごとに足し、間が60秒より空いた分（眠っていた間）と期限を過ぎた分は数えない
- 同じ役目のアプリ（Amphetamine・KeepingYouAwake・Caffeine・Lungo）が動いていると、起動時とそのアプリが起動したときに通知し、メニューにも「二重」と出る
- 宣言が出せなかったときは、アイコンは「眠れる」のまま・メニューに「宣言できず」

## 仕組み
- 眠らせない宣言（IOPMAssertion）を出すだけ。`PreventUserIdleSystemSleep`（本体）と、画面もなら `PreventUserIdleDisplaySleep`。名前は `TsumikiWake`（`pmset -g assertions` で見える）
- **電源の設定（pmset）は書き換えない。** アプリが終われば宣言は消える＝必ず元どおり
- ふたを閉じても眠らない機能は作らない（pmset の書き換えと管理者の権限が要るため）
- 許可は要らない（アクセシビリティも画面収録も不要）。通知だけ初回に聞かれる

## 組み立て
```
./build.sh                      # 自己テストが通ったら ~/Applications/TsumikiWake.app に置く
./package.sh ~/Desktop/x.zip    # Apple シリコン・Intel 両対応の zip（公証なし）
./notarize.sh ~/Desktop/x.zip   # 公証済みの zip（Developer ID・notarytool の保存名 tsumikishot）
```
- 自己テスト `TsumikiWake --selftest`：時間の計算・時刻まで・電池の判定・二重の検出・本体（使い捨ての設定で開始→画面を外す→延長→時間切れ→電池→記録）・本物の宣言が出て消えること・アイコン3通り
- `--menu-icons <フォルダ>` でメニューのアイコン3通りを大きく書き出す（見た目の確認用）

## App Store 版について（まだ作らない）
つみきショットの `appstore.sh`・`AppStore.entitlements`・`-D APPSTORE` の形にそのまま乗れる見込み。眠らせない宣言・電池の読み取り・起動中のアプリの一覧・ショートカット（Carbon のホットキー）・ログイン項目（SMAppService）は、どれも箱の中（サンドボックス）で動く。変える所は「`-D APPSTORE` のときは既定のキーを Mac 標準と重ねない」程度。未検証。
