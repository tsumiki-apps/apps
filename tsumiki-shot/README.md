# つみきショット（Mac のスクショ・自分専用）

メニューバーに常駐するスクショアプリ。

| 操作 | キー（既定） | 中身 |
|---|---|---|
| 範囲 | ⌥⇧4 | ドラッグで選ぶ。Esc・右クリックで取消 |
| 全画面 | ⌥⇧3 | マウスのある画面 |
| スクロール | ⌥⇧S | 範囲を選び、手でゆっくりスクロール（縦でも横でも）か、札の ▶︎ で自動スクロール → 札の ✓ かもう一度 ⌥⇧S |
| ウィンドウ | ⌥⇧W | 指した窓が色で囲まれる → 押すとその窓だけ（重なった窓は写らない） |
| 録画 | ⌥⇧R | 範囲を MP4 に（赤い枠・経過時間）。札の ■ かもう一度 ⌥⇧R。できた動画はファイルとして貼れる |
| 文字を読む | ⌥⇧T | 範囲の文字をクリップボードへ（日本語・英語・端末の中で読む） |

- 保存先：`~/Pictures/つみきショット/`（PNG）＋クリップボード
- 撮った直後に左下へ小窓：押すと開く・ドラッグで他のアプリへ・ボタンはアイコンだけ（指を乗せると説明）：鉛筆＝書き込み・ピン＝画面に浮かべる（ドラッグで移動・ダブルクリックか Esc で閉じる・右クリックでコピー）・フォルダ＝Finder・8秒で消える（指を乗せている間は残る）
- 編集：矢印・四角・文字・モザイク、⌘Z で戻す、⌘S で保存＝元は残して「〜 編集.png」を横に作る（＋クリップボード）
- **設定（メニュー →「設定…」）**：ショートカットを好きなキーに（欄を押してキーを押す・delete＝なし・esc＝やめる・⌘⌃⌥ のどれかが要る／F キーは単独可）。同じキーを2つに付けると古いほうはなしになる。他のアプリが使っているキーは ⚠︎（メニューにも ⚠︎）。項目ごと・すべての既定に戻す。ログイン時に起動
- **自動スクロール**：札の ▶︎ で、範囲の真ん中にホイールの合図を1コマごとに送る（範囲の高さの3割ずつ）。動かなければ下→上→右→左と向きを試し、一度継げたらその向きに決める。送りすぎ（×）は少し戻して量を半分に。継いだあと4コマ続けて動かなければ端＝自動で仕上げる。手でスクロール・クリック・キーを触ると自動をやめて手動に戻る（自分の合図は数えない）
- 許可：「画面収録」。自動スクロールを使うときだけ「アクセシビリティ」も（初めて ▶︎ を押したときに案内）

## スクロールのつなぎ方（`Stitcher.swift`）
0.12秒ごとに範囲を撮り、行ごとの指紋（横32区画の明るさ）で前のコマと比べる。
上下で同じ位置に同じ行が続く帯＝固定ヘッダー／フッターとして外し、真ん中の帯のずれ＝スクロール量だけ継ぎ足す。
比べる相手は最後に採ったコマ＝戻ってもまた進めば続きから。重なりが見つからない（速すぎ）が続くと枠が赤くなり「ゆっくり」。
同じ模様の繰り返しなどで「ずれが1つに決まらない」ときは、まちがえて継ぐより継がないほうを選ぶ。画素の上限（1.6億）に達したら「上限」と出してそこで仕上げる。
- 横スクロールはコマを90°回して縦として継ぎ、できあがりを戻す。最初は縦と横の両方で試し、はっきり多く進んだ向きに決める（24px以上かつもう片方の2倍以上。ゆっくり横に送っても縦と取り違えない）。横は下端のスクロールバーを指紋から外し、色空間を保ったまま回す。横の画素の上限は縦の半分
- 縦のとき、左右に動かないサイドバー（Slack・Finder など）があるアプリは、スクロールする列だけを範囲に選ぶ（横のときは左右の固定帯は自動で外れる）

## 組み立てと検査
```
swift make_manual.swift 説明書.pdf   # 説明書（PDF・5ページ・SF Symbols）
./build.sh                       # 自己テスト（つなぎ19種（横7種を含む）＋横長ページのゆっくり送り・回す向き・画素まで照合／書き込み・文字読み・編集画面・自動スクロール（架空のページで端まで・逆向き・横）・ショートカットの保存と重なり・設定の窓）→ ~/Applications/TsumikiShot.app
open -W --stdout 結果.txt ~/Applications/TsumikiShot.app --args --probe 出力.png   # 本物の撮影を通した通しテスト（要・画面収録の許可）
```
- `-target arm64-apple-macos15.0` を外さない（外すと SDK の版が最低条件になり、この Mac で起動できない）
- 署名は毎回同じ開発者証明書（変えると画面収録の許可が外れる）
