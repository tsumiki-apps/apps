# つみきショット（Mac のスクショ・自分専用）

メニューバーに常駐するスクショアプリ。アイコンは明るい地に積み木ひとつと撮影の枠（`Icon.swift` でコードから描く。メニューバーは1色のテンプレートで、明るい/暗いメニューバーに自動で合う）。

| 操作 | キー（既定・CleanShot X と同じ並び） | 中身 |
|---|---|---|
| 範囲 | ⇧⌘4 | ドラッグで選ぶ。ドラッグ前に Enter でマウスのある画面をまるごと。スペースでウィンドウ選びに切り替え（Mac と同じ）→ 窓を指して Enter かクリック。Esc・右クリックで取消 |
| 全画面 | ⇧⌘3 | マウスのある画面 |
| スクロール | ⇧⌘5 | ①範囲を選ぶ → ②札で向き（↓縦・→横）→ ③札の ▶︎ 自動で端まで（手でゆっくりスクロールしても継ぐ）→ 端で自動で仕上げ。途中でやめるなら札の ✓ かもう一度 ⇧⌘5 |
| 録画 | ⇧⌘6 | 範囲を MP4 に（赤い枠・経過時間）。札の ■ かもう一度 ⇧⌘6。できた動画はファイルとして貼れる |
| 注釈 | ⇧⌘7 | 保存先でいちばん新しい画像（直前のスクショ）を編集画面で開く。1枚も無ければ画像を選ぶ。保存は元の隣に「◯◯ 編集.png」（書けなければ保存先へ） |
| ウィンドウ | ⇧⌘8 | 指した窓が色で囲まれる → クリックか Enter でその窓だけ（重なった窓は写らない）。Esc で取消 |
| 文字を読む | ⇧⌘2 | 範囲の文字をクリップボードへ（日本語・英語・端末の中で読む）。ドラッグ前に Enter で画面まるごと |

- 保存先：既定は `~/Pictures/つみきショット/`（PNG）＋クリップボード。設定の「保存先 → 変更…」で好きなフォルダに（消えた・書けないときは既定に保存・↺で既定に戻す）
- Mac 標準のスクショのキー（⇧⌘3・⇧⌘4・⇧⌘5・コピー用の ⌃⇧⌘3・⌃⇧⌘4）と重なるときは、初回の起動で「止めますか」と聞く。設定の「Mac 標準のスクショのキーを止める」でいつでも切り替え（システム設定のキーボードショートカットと同じ場所を書き換える）

## 別の Mac で使う
1. この Mac で `./package.sh ~/Desktop/TsumikiShot.zip`（Apple シリコン・Intel 両対応の .app を zip に）
2. 別の Mac で zip を開き、`TsumikiShot.app` を「アプリケーション」へ入れる
3. 公証していないので、初回は「開けません」と止められる → そのまま システム設定 → プライバシーとセキュリティ を開き、下の方の「このまま開く」を押す（macOS 15 からは右クリック →「開く」では通らない）
4. 画面収録（とスクロールの自動を使うならアクセシビリティ）を許可して、開き直す

### App Store に出す
`./appstore.sh <版> <組番号>`（例 `./appstore.sh 1.0 1`）。App Store 版は `-D APPSTORE` で組み立て、箱の中（サンドボックス・`AppStore.entitlements`）で動く。違い：既定のキーは ⌥⇧⌘（Mac 標準と重ねない）・「Mac 標準のキーを止める」は無い・自動スクロールは「入力を送る」許可・選んだ保存先はブックマークで覚える。前準備（有料の Developer Program・証明書・プロファイル）は appstore.sh の先頭。プライバシーポリシー＝https://tsumiki-apps.com/shot-privacy.html

### 公証して渡す（会社の Mac など、止められて開けないとき）
有料の Apple Developer Program に入っていれば、`./notarize.sh ~/Desktop/TsumikiShot.zip` で公証済みの zip を作れる（そのまま開ける）。前もって1回だけの準備は notarize.sh の先頭に。会社の Mac に入れるときは、先に社内の担当に確認する
- 撮った直後に左下へ小窓：押すと開く・ドラッグで他のアプリへ・ボタンはアイコンだけ（指を乗せると説明）：鉛筆＝書き込み・ピン＝画面に浮かべる（ドラッグで移動・ダブルクリックか Esc で閉じる・右クリックでコピー）・フォルダ＝Finder・8秒で消える（指を乗せている間は残る）
- 編集：道具14個＝選ぶ V・矢印 A・線 L・四角 R・塗り F・丸 O・ペン P・蛍光ペン H・文字 T・番号 N・モザイク M・ぼかし B・スポット S・切り抜き C（return で確定）。色7色・太さ3段（1〜3）、shift で45°・正方形・正円
  - 選ぶ：押して選ぶ・ドラッグで動かす・矢印キーで少しずつ（shift で10倍）・delete で消す。選んだ書き込みに色と太さが効く。文字はダブルクリックで直す
  - ⌘Z で戻す・⇧⌘Z でやり直す（切り抜きも戻せる）
  - 下の段：背景（余白・地の色6種・角丸・影）・ドラッグで他のアプリへ・ピン・コピー（⌘C）・保存（⌘S）＝元は残して「〜 編集.png」を横に作る（＋クリップボード）
- **設定（メニュー →「設定…」）**：ショートカットを好きなキーに（欄を押してキーを押す・delete＝なし・esc＝やめる・⌘⌃⌥ のどれかが要る／F キーは単独可）。同じキーを2つに付けると古いほうはなしになる。他のアプリが使っているキーは ⚠︎（メニューにも ⚠︎）。項目ごと・すべての既定に戻す。ログイン時に起動
- **自動スクロール**：札の ▶︎ 自動で、範囲の真ん中にホイールの合図を送る（範囲の高さの3割ずつ）。合図は0.6秒以上あけ、ページが動いている間は止まるのを待ってから次を送る（`AutoDriver`）。合図の正負はナチュラルスクロールやアプリで逆になりうるので決め打ちしない＝ページが戻ったら（ページの途中から始めたとき）すぐ同じ軸の逆向きに切り替え、端で動かなければ逆向きを試す。送りすぎ（×）は少し戻して量を半分に。合図を9回送っても動かなければ端（約5秒＝続きを読み込むページを待つ）＝自動で仕上げ、カーソルを元の位置に戻す。手でスクロール・クリック・キーを触ると自動をやめて手動に戻る（自分の合図は数えない）。撮影中の Esc は、自動中なら自動だけ止め、それ以外は取り消す。上限・継ぎ目の見失い・1回も動かない・撮れなくなった（約3秒）で終わったときは、保存したあと下に知らせを出す（黙って普通の撮影と同じにしない）
- 許可：「画面収録」。自動スクロールを使うときだけ「アクセシビリティ」も（初めて ▶︎ を押したときに案内）

## スクロールのつなぎ方（`Stitcher.swift`）
0.12秒ごとに範囲を撮り、行ごとの指紋（横32区画の明るさ）で前のコマと比べる。
上下で同じ位置に同じ行が続く帯＝固定ヘッダー／フッターとして外し、真ん中の帯のずれ＝スクロール量だけ継ぎ足す。
比べる相手は最後に採ったコマ＝戻ってもまた進めば続きから。戻る向きに回すと（ナチュラルスクロールで逆に回したときなど）枠が赤くなり「逆向き」と出る（戻った分は継がない）。重なりが見つからない（速すぎ）が続くと枠が赤くなり「ゆっくり」（手でスクロールしているとき。自動は自分で戻して送る量を半分にする）。
同じ模様の繰り返しなどで「ずれが1つに決まらない」ときは、まちがえて継ぐより継がないほうを選ぶ。画素の上限（1.6億）に達したら「上限」と出してそこで仕上げる。
比べ方は崩れに強くしてある：①ページが動いたのに同じ位置で変わらない列（縦の固定サイドバー）とその隣の列は比べない ②行の指紋からその行の平均を引いて比べる（透けるヘッダー・背景の明るさの変化に引きずられない。表や同じ形のカードの一覧に動画や広告の帯が重なっても、別の周期のずれで継がず「見失った」側に倒れる）③上の固定帯で合わなければ、上も含めて探し直す（ページ先頭の白い余白を固定ヘッダーと取り違えても、その後を継げる）。
残る苦手：透けるヘッダーは一度に大きく送ると継げない（自動は送る量を半分にして継ぐ）。同じ形の行が並ぶ所に動く帯が重なると、継げずに止まりやすい（まちがえては継がない）。背景が縦にはっきり変わるページで大きく送ると継げないことがある。
保存は Retina なら 144dpi を書く（他のアプリで2倍の大きさに見えない）。保存できなかったときも、撮った絵はクリップボードに残す。
- 横スクロールはコマを90°回して縦として継ぎ、できあがりを戻す。向きは札で選ぶ（↓縦・→横）。自動は選んだ向きの中で、送る向き（下／上・右／左）を試し、どちらでも動かなければ終わる。継いだ後は約5秒動かなければ端（続きの読み込みを待つ間、札に「待機」）。横は下端のスクロールバーを指紋から外し、色空間を保ったまま回す。横の画素の上限は縦の半分
- 縦のとき、左右に動かないサイドバー（Slack・Finder など）は自動で比べる列から外す。外れきらない（サイドバーの中も動く等）ときは、スクロールする列だけを範囲に選ぶ

## 組み立てと検査
```
swift make_manual.swift 説明書.pdf   # 説明書（PDF・5ページ・SF Symbols。表紙のアイコンは ./build.sh の後に入る）
./build.sh                       # 自己テスト（つなぎ25種（横7種を含む。固定サイドバー・透けるヘッダー・表・動く帯・表＋動く帯・先頭の白い余白も）＋横長ページのゆっくり送り・回す向き・画素まで照合／書き込み・文字読み・編集画面・自動スクロール（架空のページで端まで・逆向き・途中から逆向き・横・滑らかに動き続きを読み込むページ）・ショートカットの保存と重なり・設定の窓）→ ~/Applications/つみき/TsumikiShot.app
open -W --stdout 結果.txt ~/Applications/つみき/TsumikiShot.app --args --probe 出力.png   # 本物の撮影を通した通しテスト（要・画面収録の許可）
```
- `-target arm64-apple-macos15.0` を外さない（外すと SDK の版が最低条件になり、この Mac で起動できない）
- 署名は毎回同じ開発者証明書（変えると画面収録の許可が外れる）
