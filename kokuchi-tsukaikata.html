告知づくり 使い方

チームへの告知を、16:9の画像にする道具です。型を選んで、画像と文字を入れて、保存するだけ。

まず、これだけ

1

上の3つから型を選ぶ新しい研修・お知らせ・未完了の人

2

画像と文字を入れる左の画像にすぐ反映されます

3

画像を保存を押すチャットに貼れば告知のできあがり

どこを書き換えられるかは「型ごとに書く」に番号つきで載せています。

大切なこと

  • 入れた内容はこの端末の中だけ 別の端末やブラウザでは、まっさらから始まります。
  • 型ごとに1つしか覚えない 次の告知を書くと、前の内容は上書きされます。
  • 画像が無いと保存できない 点線の枠のまま配らないための決まりです。

巻末

こまったとき

まず知る

1どんな道具か

告知の画像を、決まった型にはめて作ります。毎回レイアウトを組み直す必要がありません。

できる画像は 3840×2160（16:9）。大きな画面に映しても粗くなりません。

2画面の見かた

①型の切り替え ②できあがりの画像 ③入力欄 ④保存ボタン。打つたびに②がすぐ変わります。

Macでは左に画像・右に入力欄。iPhoneでは画像が上に残ったまま、入力欄だけ動きます。

画像を入れる

3選んで入れる

入力欄のいちばん上の選ぶから、研修の画面やPDFのスクショを選びます。

入れた画像は、型ごとに別々に覚えます。長い辺が2400pxを超える画像は自動で縮めます。

4貼り付け・ドロップ

Macでは、コピーした画像を ⌘V で貼るか、ファイルを画面に落とすだけで入ります。

いま開いている型の画像が入れ替わります。

5画像を外す

外すで、その型の画像だけ消えます。文字はそのまま残ります。

型ごとに書く

6新しい研修

  1. 1研修の画面枠の左上に寄せて置きます
  2. 2見出し（黒）
  3. 3見出し2（赤）長いと2つそろって小さくなります
  4. 4研修名長いと折り返します。空なら出しません
  5. 5締切
  6. 6注意空にすると、札ごと消えます

7お知らせ

  1. 1実物PDFの表紙など。右に少し傾けて置きます
  2. 2号「NEW」の横に入ります
  3. 3見出し改行で3行まで
  4. 4ひとこと（黒）
  5. 5ひとこと2（紫）

8未完了の人

  1. 1研修の画面枠の左上に寄せて置きます
  2. 2お願いする相手「◯◯へサポートのお願い📚」になります。空なら「サポートのお願い📚」
  3. 3締切「期限◯◯が迫っている…」に入ります
  4. 4研修とリンク1行目に題名、2行目にURL。空行で区切って4件まで。URLには下線が付きます
  5. 5終わっていない人1行に1人。多いと2列→3列になり、字が小さくなります

9変えられない所

背景・色・字の形・置く位置・アイコンの列・アプリのアイコン・「NEW」・未完了の人の決まり文句は固定です。

字の大きさは自動です。長い文字は入る大きさまで縮み、それでも入らない分は「…」で切れます。固定の所を変えたいときは、Claude に「告知づくりの◯◯を変えて」と頼んでください。

保存する

10Macで保存

画像を保存で、いつものダウンロード先にPNGが入ります。

名前は「告知_型の名前_日付_時刻.png」。同じ日に何枚作っても重なりません。

11iPhone・iPadで保存

共有の画面が開くので、画像を保存を選ぶと写真に入ります。

「もう一度押してください」と出たら、もう一度押せば開きます（画像の用意が間に合わなかったときだけ出ます）。

12赤い知らせが出たら

保存ボタンの上に、入りきらなかった所が出ます。文字を短くするか、行を減らしてください。

知らせが出ていても保存はできます。消えた分は画像に入っていないので、見てから配ってください。

ルール・置き場

13入れた内容の置き場

文字と画像は、このブラウザの中だけに残ります。どこにも送りません。

ブラウザの履歴やデータを消すと、入れた内容も消えます。

14ホーム画面に置く

iPhone・iPad：Safariで開き、共有 → ホーム画面に追加。

Mac：Safariのメニュー ファイル → Dockに追加。

ホーム画面から開いたものと、Safariで開いたものは、覚えている内容が別々です。

こまったとき

PDFが入らない
入れられるのは画像だけです。PDFは開いてスクショを撮り、それを入れてください。
開き直したら画像が消えていた
画像が大きすぎて覚えきれなかったときです（そのとき赤い知らせが出ます）。もう一度入れてください。
名前が小さすぎる
人数が多いと列が増えて字が小さくなります。2回に分けて告知するのも手です。
リンクが5件目から出ない
4件までです。5件以上なら、画像を2枚に分けてください。

直したい所があるとき

Claude に「告知づくりの◯◯を変えて」と頼む。型を増やすこともできます。
