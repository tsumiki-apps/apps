# つみきリモート

Mac の tmux セッション（＝Claude Code などを走らせている画面）を、
iPhone から見て・指示を返せるようにする自作アプリ。

蓋は開けたまま、画面だけ消して Mac は動かし続ける。外出先からは Tailscale 経由で届く。

```
iPhone (PWA)  ──https──▶  Tailscale  ──▶  Mac:8787 (server.js)  ──▶  tmux  ──▶  Claude Code
```

## 中身

| ファイル | 役割 |
|---|---|
| `server.js` | 依存パッケージなしの小さなHTTPサーバー。tmux にコマンドを投げるだけ |
| `public/index.html` | スマホ用の画面（単一HTML・PWA）。1.5秒ごとに状態を取りに行く。版が変わったら自分で読み込み直す |
| `~/.tsumiki-remote/archived.json` | 片付けた作業場所の名前。tmux は消さない |
| `hooks/ntfy-notify.sh` | Claude Code の hook から ntfy.sh に「返答待ち／終わった」を通知 |
| `launchagents/*.plist` | ログイン時に ①サーバー ②caffeinate を自動起動 |

## 題名（どれがどれか）

`work1` のような機械の名前ではどれがどれか分からないので、**ターミナルの題名
（tmux の `#{pane_title}`）を題名として使う**。Claude Code はここに「いま何をしているか」
を書き込んでいる。

```
work1 → ⠐ Obsidianで JR ビューン申し込み内容を確認
work2 → ⠐ つみきリモートの閉じるボタン機能を修正
```

- 先頭のスピナー（`⠐` などの点字）は落とす。60文字で切る
- 題名が無い＝ホスト名やパスが入っているだけ（素のシェル）なら**フォルダ名**に落とし、
  それも無ければセッション名に戻す
- 題名の置き場は**タブ**。折り返して**全文**出す（`max-width:11.5em` で横幅を止め、
  伸びるのは縦だけ）。横に伸ばすと隣のタブが画面から消えて切り替え先が見えなくなる
- 状態（待機/作業中）と種類（Claude/シェル）は**同じ行**に置く。題名が2〜3行に
  なるぶんをここで返す。iPhone 幅390pxでタブは172×69px、2枚＋次の頭が見える
- ⚠️ 題名は60文字まで。**60文字だとタブが137px**まで伸びて画面を圧迫する。
  実際の Claude Code の題名は20文字前後なので2行で収まっているが、
  長い題名が続くようなら `.tab .n` の `max-width` を広げるか行数を止める
- 一番上の「つみきリモート」はそのまま（アプリ名を残す）
- 「片付けたものを戻す」も題名で出す（`work3` だけでは何を戻すのか分からない）

## 状態の見かた

| 表示 | 判定 |
|---|---|
| **作業中** | 画面に `esc to interrupt` やスピナーがある／直近5秒で画面が動いた |
| **返答待ち** | 画面に `Do you want` `❯ 1.` `(y/n)` などの選択肢が出ている |
| **待機** | 5秒以上なにも動いていない |

判定に使うのは「いま見えている画面」だけ。スクロールバックを混ぜると、
一度出た `Do you want…` が永遠に残って返答待ちに見えてしまう。

## セットアップ

### 1. 常駐（済）

```bash
launchctl list | grep tsumiki
```

`com.tsumiki.remote`（サーバー）と `com.tsumiki.awake`（caffeinate）が出れば動いている。

止めたいとき:

```bash
launchctl unload ~/Library/LaunchAgents/com.tsumiki.awake.plist
```

### 2. 画面だけ消す

**Control + Shift + 電源ボタンは Touch ID 搭載機では効かない。** 電源ボタンが
Touch ID センサーになっていて、修飾キーの組み合わせとして認識されないため。
代わりに次のどれかを使う。

| 手段 | やりかた |
|---|---|
| 専用アプリ | `~/Applications/画面を消す.app`（Dock に置いて1クリック） |
| アプリから | つみきリモートのヘッダーの **消灯**（外出先からでも消せる） |
| コマンド | `pmset displaysleepnow` |
| ホットコーナー | システム設定 → デスクトップとDock → ホットコーナー → 隅に「ディスプレイをスリープさせる」 |

`caffeinate -ims` を常駐させてあるので、画面が消えても Mac は眠らない。
（`-d` を付けていないので「画面は消える」。付けると画面も点いたままになる）

**⚠️ Amphetamine と喧嘩する。** Amphetamine が「ディスプレイも起こしておく」
セッションを持っていると、何で消しても画面がすぐ復帰する。今回の目的
（蓋は開けたまま画面だけ消す）とは真逆なので、そのセッションは終了しておく。
眠らせない役目は `com.tsumiki.awake` が担っているので Amphetamine は不要。

### 3. Tailscale（外から繋ぐ）— sudo なしで動かす

公式の案内は `sudo brew services start tailscale` だが、それだと管理者権限が要る。
**userspace-networking モード**なら一般ユーザー権限のまま動く。

```bash
launchctl load ~/Library/LaunchAgents/com.tsumiki.tailscaled.plist
```

このモードでは OS のネットワーク層に入らない代わりに、
**外から入ってきた接続は localhost の同じポートへ転送される**。
今回欲しいのは「iPhone → Mac:8787」の向きだけなので、これで足りる。

CLI は毎回ソケットの指定が要る（普段の `tailscale` コマンドとは別物になる）:

```bash
alias ts='tailscale --socket=$HOME/.tsumiki-remote/tailscaled.sock'
ts status
ts ip -4
```

ログインは `ts up` が出す URL をブラウザで開いて認証する。

サーバーは `127.0.0.1` にしか口を開けていないので、Tailscale を通した以外の経路では
一切届かない（ルーターのポート開放も不要）。

`https://…ts.net/` の名前で開きたい場合だけ、管理画面で HTTPS を有効にしたうえで
`ts serve --bg 8787`。名前が要らなければ `http://<tailscale IP>:8787` で足りる。

### 4. iPhone 側

1. App Store で **Tailscale** を入れて同じアカウントでログイン、VPN を常時ONにする
2. `./bin/qr.sh` が出す QR を iPhone のカメラで読む（URL にトークンが入っている）
   - 一度開けば端末に保存され、URL からは自動的に消える
   - 手打ちするなら `http://<tailscale IP>:8787/?t=<トークン>`（`cat ~/.tsumiki-remote/token`）
   - **QRとURLはトークン入り。人に見せない・スクショを配らない**
3. 共有 → **ホーム画面に追加**。以後アイコンから全画面で起動する

### 5. 通知（ntfy）

1. App Store で **ntfy** を入れる
2. トピックを購読: `cat ~/.tsumiki-remote/ntfy-topic`
3. Claude Code が**こちらの返事で止まったとき**に通知が来る

鳴るのは `PermissionRequest`（許可待ち）と `Notification`（入力待ち）の2つだけ。
`Stop`（1ターンの応答完了）にも付けていたが、**返答のたびに鳴って実用にならない**ので外した。

送っているのは **イベント名と tmux のセッション名だけ**。
会話の中身・ファイル名・コマンドは外に出さない。

## ＋Claude の起動オプション

このアプリから作るセッションは **編集をバイパス**（`--permission-mode bypassPermissions`）で
起動する。スマホから「これ実行していい？」に毎回答えるのは現実的でないため。

**副作用**：許可を求めて止まらなくなるので、**返答待ちの通知はほとんど飛ばなくなる**。
通知が来るのは、Claude が選択肢つきで質問してきたときだけになる。

初回だけ「Bypass Permissions mode を受け入れますか」の確認が出る。`2` を選べば以後は出ない。

普通の権限確認つきに戻したいときは、LaunchAgent に環境変数を足す:

```
TSUMIKI_CLAUDE_CMD=claude
```

## 画面の塗り分け

行頭の記号で「誰の言葉か」を判定して、かたまりごとに薄く色を敷く。

| 対象 | 手がかり | 見た目 |
|---|---|---|
| Claude の返答 | `⏺ ふつうの文` | 緑をごく薄く＋左に緑の線 |
| 選択肢（許可待ち） | `│ ╭ ╰` の枠 | オレンジ＋左にオレンジの線 |
| 自分が打った行 | `❯` | 白をごく薄く |
| ツールの呼び出し・結果 | `⏺ Bash(...)` `⎿` `✻` | **塗らない**（読まなくていい合図） |

黒地に彩度の高い色を敷くと文字が沈むので、面はごく薄くし、手がかりは左端の線に持たせている
（紙の蛍光ペンが成立するのは白地だから）。字下げ行と空行は直前のかたまりの続きとして扱う。

## 制作物を見る

**やり取りの中で出力したもの**（レポート・図・調査結果・単発のHTMLなど）を
**このアプリの中で**開く。ヘッダーの **⋯ → 制作物を見る**。「もどる」でターミナルに戻る。

置き場は **iCloud Drive の `つみきリモート` フォルダ**。Mac からは `~/つみき出力/` で入れる
（シンボリックリンク）。iCloud なので **iPhone のファイルアプリからも開ける**。

- **アプリから出ない**のが要件。別タブに飛ばすと「アプリ上で見る」にならない
- 人に渡したいときだけ「Safariで開く」→ 共有 → ファイルに保存 / AirDrop
- 認証は「最初の1回だけURLに `?t=`、あとはクッキー」。CSS や画像の追加読み込みに
  トークンを載せられないため（`HttpOnly` / `SameSite=Lax` / 30日）
- 置き場の外は出さない。`../` も絶対パスも、シンボリックリンクの飛び先も `realpath` で確認

### ⚠️ iCloud は必ず非同期で読む

`readdirSync` で読んだら **opendir が返ってこず、サーバーが丸ごと止まった**
（CPU 0%・ポートは LISTEN のまま・全機能が無応答）。iCloud 配下を触るコードは
**非同期＋制限時間（4秒）つき**にすること。1本のループで動くサーバーでは、
1回の停止が機能全体の停止になる。

## 画像を送る

入力欄の左の **＋**。Claude Code は画像そのものを受け取れないが、
**ファイルの場所を渡せば読める**ので、Mac に置いてからそのパスを入力欄に差し込む。
勝手に送信はしないので、「この画像の文字を起こして」などを書き足してから送る。

- 置き場は `~/.tsumiki-remote/uploads/`。**7日たったものは次の送信時に消す**
- 拡張子はファイル名ではなく中身（マジックバイト）で判定。画像でなければ弾く
- 上限10MB。iPhoneの写真は Safari が JPEG に変換して送ることが多い

## 作業場所を片付ける

**⋯ → この作業場所を片付ける**。これは **消さない**。tmux セッションはそのまま動き続け、
**このアプリの一覧から隠すだけ**。使い終わったものが並び続けて邪魔になるのを避けるための機能。

- 戻すのは **⋯ →「片付けたものを戻す」**（片付けたものがあるときだけ出る）
- 片付けた記録は `~/.tsumiki-remote/archived.json`。tmux 側で消えたセッションは自動で落ちる
- **片付けたものは状態も見えなくなる**。返答待ちになっても一覧に出ないので、
  返事が要る作業は片付けない
- 落とすのは **tmux の一覧が取れたときだけ**。tmux が答えなかった（時間切れ等）ときは
  片付けリストに触らない。0件と区別しないと、一度の失敗で片付けたものが全部戻ってくる

本当に終わらせたいときは、中で `/exit`（Claude）や `exit`（シェル）、
または Mac から `tmux kill-session -t work2`。

## 版（アプリの更新）

**ホーム画面アプリは一度開くと開きっぱなしになる。** Mac 側でこのアプリを直しても、
iPhone は前の画面を動かし続けるので、ボタンを押しても古い動きをする
（2026-08-11：削除済みの `/api/kill` を呼び続けて「押しても何も起きない」になった）。

- サーバーは `public/index.html` と `server.js` の中身のハッシュを「版」として
  `/api/state` で配る。画面は版が変わったら自分で読み込み直す
- 読み込み直す前に**入力欄の書きかけを預けて、開き直したあと戻す**
- 手動の逃げ道は **画面右上の ↻**（いまの版は ⋯ の見出しに出る）
- ファイルを touch しただけ（中身が同じ）では版は変わらない。
  サーバー再起動だけでも変わらない
- ⚠️ **古い画面はこの仕組みを持っていない**。仕込む前に開いた画面は、
  一度だけ手で開き直す（アプリスイッチャーから上スワイプで終了 → 開き直し）

## 注意

- ntfy.sh は外部サーバー。トピック名を知っている人は誰でも購読できるので、
  トピック名は共有しない（`~/.tsumiki-remote/ntfy-topic` は 600）。
- 蓋を開けたままの連続運用は、閉じた状態（クラムシェル）より排熱で有利。
  それでも長時間まわすときは電源接続で。
- このアプリは GitHub Pages では動かない（Mac 上のサーバーが要る）ので、
  `apps/index.html` には載せていない。
