# つみきトレイ（Mac のドラッグの一時置き場）

ファイル・文字・画像・URL をドラッグしている間だけ、画面の端に棚が出る。そこに一時的に置いておき、あとで別の場所へドラッグして取り出す。メニューバーに常駐。アイコンはトレイのくぼみに積み木を乗せた形（`Icon.swift` でコードから描く。メニューバーは1色のテンプレート）。

| 操作 | キー | 中身 |
|---|---|---|
| 出す・しまう | ⇧⌘9 | 棚の出し入れ（Carbon のホットキー＝許可は要らない） |
| 出さずに運ぶ | Fn ＋ドラッグ | ドラッグの合図に付いた印と、キーボードそのものの状態の両方を見る |
| のぞく | スペース | クイックルック。文字・URL も一時ファイルにして見せる |
| 消す | ⌫ | 棚から外すだけ（元のファイルは消さない） |
| 選ぶ | ↑ ↓ | 棚の中で |

- **棚**：右端の縦の真ん中（メニューの「位置」で左にも）。3つ見える高さ。マウスが離れて約1.2秒で端にしまい、細い取っ手だけ残る（「端にしまう」をオフにすると、しまわずに出たまま。⇧⌘9・Esc で消す）。空になったら取っ手も消える。取っ手に触れる・ドラッグが来るとすぐ出る
- **入った知らせ**：棚をしまっている間に入ったとき（「このアプリで開く」・つみきショットの「トレイへ」）は、棚は出さずに取っ手を出して2回またたく
- **置いた物**：ファイルは「場所の控え」（ブックマーク）だけ持つ。元が名前を変えたり動いたりしても追いかけ、消えたら薄く表示。文字・URL・画像・写真アプリなどの「約束のファイル」は中身をアプリ側に持つ。複数のファイルは1つの山にまとめ、右クリックの「ばらす」で分ける
- **取り出し**：いつもコピーだけを許す（移動・削除・ゴミ箱を許さない＝元を動かさない）。「取り出したら消す」は既定でオン＝取り出した後に棚から外す（オフにすると残る）
- **受け取り**：相手が許す操作から コピー → 何でも → リンク の順に選ぶ。移動しか許さないドラッグは受けない（渡した側が元を消すことがあるため）。ブラウザのリンクに付いてくる「約束のファイル」（.webloc）より URL を採る
- **置き場**：`~/Library/Application Support/TsumikiTray/`。試すときは `--store <フォルダ>` で分ける
- 通信しない。アクセシビリティ・画面収録などの許可は要らない（マウスの動きと、ドラッグ用の受け渡し場所を見るだけ）

## 組み立てと確かめ
- `./build.sh`：自己テスト（`--selftest`、架空のファイルで）が通ったら `~/Applications/つみき/TsumikiTray.app` に置く。動いていたら新しい版で起動し直す
- `--render <出力.png>`：棚（空・置いた後・しまった取っ手）をライト/ダークで1枚に描く

## 配る
- `./notarize.sh <出力.zip>`：Apple シリコン・Intel 両対応で組み立て、公証して印を貼った zip（`._` を入れない）。前準備は notarize.sh の先頭（キーチェーンのプロファイル名は `tsumikishot` を共用）
- `./package.sh <出力.zip>`：公証しない zip（初回は「このまま開く」が要る）
- 配布ページ：https://tools.tsumiki-apps.com/tsumiki-tray.html（`~/tsumiki-tools/tsumiki-tray.html` と `tsumiki-tray.zip`）
