**狙い2つ**
- **2枚目を最も詰め込み、3枚目を最も空にする。** 「課題（散らかっている）→ 解決策（静か）」を、
  文字ではなく情報量の落差で見せる。ここが8枚の中でいちばん効く。
- **人は1・2・4だけ。** 前半＝人の話、後半（5〜8）＝事業の構造、と絵の種類そのものを切り替える。

## 1｜ビジョン ✅ 完成済み（`01_A案_人と積み木.png`）

```
1枚目です。前のルールを守って描いてください。

題材：左に人が1人。頭の丸と上半身のアーチだけで描く。
体から短い線を1本、右へ伸ばして腕にする。その腕の先に、小さな積み木が3つ積んである。
積み木は角の丸い四角。下に2つ横に並べ、その上に1つ。上の1つだけ淡いテラコッタで塗る。
足元に、地面を表す横線を1本だけ淡いグレーで引く。
画面の右半分は大きく空けておく。
```

## 2｜課題「システムにするには小さすぎ、我慢するには大きい。」

```
2枚目です。前のルールを守って描いてください。

題材：小さな事務所の机。画面の中央やや左に、横線1本と脚2本だけの簡素な机を置く。
机の上にノートパソコンを1台（台形の画面と、その中に短い横線を2本だけ）。
机のまわりに、書類が5〜6枚バラバラに散らばっている。
書類は角の丸い縦長の四角で、中に短い横線を2本だけ入れて書類らしくする。
書類は少しずつ傾きを変えて、雑然と見せる。
机の手前の縁に、付箋を3枚貼る（小さな四角）。そのうち1枚だけ淡いテラコッタで塗る。
机の左側に人が1人。頭の丸と上半身のアーチだけ。少しうつむいた姿勢にする。

散らばった書類は淡いグレーの線で、机・パソコン・人は墨色で描いてください。
この1枚だけは、あえて要素を多めにして「片づいていない」感じを出します。
ただし線を増やすだけで、影や質感は入れないでください。
画面の右3分の1は空けておく。
```

## 3｜解決策「その現場のかたちに合わせた1枚の道具を、丸ごと渡す。」

```
3枚目です。

題材：画面の中央に、スマートフォンを1台だけ。角の丸い縦長の四角。少し大きめに描く。
画面の中には、要素をほとんど入れない。
上のほうに短い横線を2本、その下に角の丸いボタンを1つ。それだけ。
ボタンの下に、朱色（#D14E26）の小さなチェックマークを1つ置く。
他には何も描かず、まわりは全部余白にする。

前の2枚目が「散らかった机」だったので、この3枚目は意図的に正反対にしてください。
要素を極限まで減らし、静かで、余白の多い画面にします。
```

## 4｜なぜ私たちが「話を聞く人が、そのまま作ります。」

```
4枚目です。

題材：画面の右寄りに、開いたノートを1冊。
見開きにするため、角の丸い四角を2つ横に並べ、真ん中に綴じ目の縦線を1本引く。
ノートの中は白紙にして、淡いグレーの罫線を3本だけ引く。
ノートの上に鉛筆を1本、斜めに置く（細長い四角と、先端の小さな三角）。
鉛筆の先の三角だけ、朱色（#D14E26）にする。

ノートの左に人が1人。頭の丸と上半身のアーチだけ。
その人の頭の上に、吹き出しを1つだけ浮かべる。
吹き出しは角の丸い四角と、下に伸びる小さな三角のしっぽ。
吹き出しの中には、淡いグレーの短い横線を2本だけ入れる。文字は絶対に入れない。
```

## 5｜競合と位置「安さでも技術力でもなく、『渡し切る』ことで立つ。」

```
5枚目です。

題材：2軸のマップ。画面の中央に、縦の線と横の線を1本ずつ引いて十字にする。
線は淡いグレーで、細く、端は自然に切る。矢印も目盛りも文字も入れない。

十字で4つに区切られた領域のうち、左上・右上・左下の3つに、
小さな円を1つずつ置く。墨色の輪郭だけで、中は塗らない。

右下の領域だけは空けておき、そこに朱色（#D14E26）の小さな丸を1つだけ、
塗りつぶして置く。この朱の丸が、画面でただ1つの色になります。

図全体は小さめにして、まわりは大きく余白にしてください。
```

## 6｜今後の展開「まず、売れる証明。次に、寝ていても入る床。」

```
6枚目です。

題材：メーターを4本、横に等間隔で並べる。
1本は、角の丸い縦長の細い四角。輪郭は墨色で、中は空。
それぞれ下から、淡いテラコッタで途中まで塗る。
満ち具合は4本とも変える（左から順に、7割・5割・3割・満杯）。
満杯になっている1本の上に、朱色（#D14E26）の小さなチェックマークを1つ置く。
4本の足元に、淡いグレーの横線を1本だけ引く。

文字・数字・目盛りは絶対に入れない。
画面の中央に置き、上下は大きく余白にする。
```

## 7｜3年後「業種の"型"が10個並び、紹介だけで回っている。」

```
7枚目です。

題材：棚に並んだ積み木。
画面の中央に、淡いグレーの横線を2本、上下に平行に引いて棚板にする。
上段と下段に、かたちの違う積み木を合わせて10個並べる。

積み木はすべて角の丸い図形。正方形・横長の四角・縦長の四角・小さな四角を混ぜ、
大きさもばらけさせる。同じかたちを2つ続けて置かない。
輪郭は墨色。10個のうち1個だけ、淡いテラコッタで塗る。

横に長く広がる構図にして、上下は大きく余白にしてください。
```

## 8｜収益モデル「買い切りで渡し切り、保守は任意の薄い床。」

```
8枚目です。

題材：4段の階段。角の丸い四角を4つ、左から右へ1段ずつ高くなるように積む。
四角はすべて同じ大きさで、輪郭は墨色。中は塗らない。
いちばん左（いちばん低い段）の1つだけ、淡いテラコッタで塗る。

階段の足元に、朱色（#D14E26）の細い横線を1本だけ引く。
線は階段の幅より少し長くして、階段全体を下から支えている床に見えるようにする。
この朱の線が、画面でただ1つの強い色になります。

文字・数字は絶対に入れない。画面の中央に置き、まわりは大きく余白にする。
```

## 出てきたら

1. 絵柄が崩れていないか確認（顔がついた／影が出た／線が太い → `スタイルプロンプト.md` の修正表）
2. ダウンロードして **`生成画像/`** に入れる。名前は `02_課題_原本.png` のように番号＋題材で。
3. 色を正式パレットに揃える（結果は `完成/` に出る）：
   ```bash
   cd ~/制作物/PRスライド_イラスト && python3 色を合わせる.py 生成画像/02_課題_原本.png 完成/02_課題.png
   ```
   Claudeに「色合わせて」と言ってもらってもOK。

4. 背景を透明にしたい場合：
   ```bash
   python3 色を合わせる.py 生成画像/02_課題_原本.png 完成_透過/02_課題_透過.png --透過
   ```

**フォルダの役割**
| | 中身 |
|---|---|
| `生成画像/` | GPTからダウンロードしたそのまま（保険・触らない） |
| `完成/` | 色を揃えたもの（紙の背景つき）。**通常はこちらを使う** |
| `完成_透過/` | 背景が透明。紙色以外の面に置くとき用 |

> ⚠️ 透過版の注意：線は墨色（ほぼ黒）のままです。**濃い色の背景に置くと線が見えなくなります。**
> 濃色スライドで使うなら、線を白にした版を別に作る必要があります（Claudeに頼めば作れます）。
