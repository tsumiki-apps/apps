# つみき PRスライド用 イラスト生成プロンプト（ChatGPT / GPT Image 用）

tsumiki-apps.com で実際に動いている線画イラストと同じ絵柄を、ChatGPTの画像生成で量産するためのプロンプト。

---

## 進め方

1. **新しいチャットを1本立てる。** スライド全部をこの1本の中で作る（絵柄が揃うため）。
2. **最初のメッセージで参照画像を添付**して、下の「① スタイル固定」を送る。
   - 添付するもの → `見本_サイトのイラスト/00_一覧（これを最初に添付）.png`
   - 余裕があれば `01_積み木の工房.png` と `02_向かい合って話す.png` も一緒に。
3. 以降は「② 1枚ぶんの指示」だけを送っていく。
4. 崩れてきたら、採用した絵をもう一度添付して「この絵柄に戻して」と言う。

> 参照画像は **tsumiki-apps.com の本物**（アニメーションを止めて静止画にしたもの）です。
> 言葉より画像のほうが効きます。必ず添付してください。

---

## ⚠️ この絵柄の最大の特徴：人を「2本の線」で描く

サイトのイラストでは、**人は「頭の丸1つ ＋ 上半身のアーチ1本」だけ**で描かれています。
顔・髪・手・指・足・服は一切ありません。腕が要るときだけ、体から短い線を1本足します。

これは絵柄の芯なので、必ず守らせてください。
**副産物として「手の指が6本になる」事故が原理的に起きなくなります。**

---

## ① スタイル固定（最初の1回だけ・参照画像を添付して送る）

```
これから、企業紹介スライドに入れる挿絵を何枚か作ってもらいます。
添付した画像が、揃えてほしい絵柄の見本です。この絵柄を最後まで維持してください。

【線】
・輪郭線だけの線画。塗りつぶしは原則なし。
・線の太さは画面全体で完全に均一（細い1本線）。強弱・入り抜きをつけない。線の端は丸い。
・影、グラデーション、ハッチング、点描、紙の質感、ふちのぼかしは一切なし。完全にフラット。

【色】※4色だけ
・線＝墨色 #242321
・補助的な細部の線＝淡いグレー #BEB9B0（主役より弱く）
・差し色＝朱 #D14E26。画面に1〜2箇所だけ、ごく小さく（落款のように）
・面を塗るときだけ＝淡いテラコッタ #F1CDBB。1〜2箇所まで
・背景＝生成り色 #F4F2EE の無地。模様・影・枠なし

【人の描き方】← いちばん大事
・人は「頭の丸1つ ＋ 上半身のアーチ1本」だけで描く。
・顔、目、口、髪、手、指、足、服は絶対に描かない。
・腕が必要なときだけ、体から短い線を1本だけ足す。
・かわいいマスコットにしない。棒人間の記号として扱う。

【もの の描き方】
・角の丸い四角、円、三角など、単純な図形の組み合わせで表す。
・積み木は「角の丸い四角」。建物は「四角＋三角屋根」。端末は「角丸の縦長四角」。
・細部を描き込まない。線の本数を最小限にする。

【構図】
・要素を詰め込まない。余白を大きく取る。主役は画面の中で小さくてよい。
・文字、数字、ロゴ、署名、枠線、キャプションは絶対に入れない。
・横長 16:9。1枚ずつ出してください。

まずは「了解」とだけ返してください。次のメッセージから題材を送ります。
```

## ② 1枚ぶんの指示（題材ごとに送る）

### 文章① 「誰もが、自分の道具で人生を整えられる世界。」

> **注意**：元の指定は「手のひらにのる、小さな積み木」ですが、この絵柄には**手が存在しません**。
> 下のA案（絵柄に忠実）を第一候補にしてください。どうしても手が要るならB案。

**A案｜人が積み木を差し出す（絵柄に忠実・推奨）**
```
1枚目です。前のルールを守って描いてください。

題材：左に人が1人。頭の丸と上半身のアーチだけで描く。
体から短い線を1本、右へ伸ばして腕にする。その腕の先に、小さな積み木が3つ積んである。
積み木は角の丸い四角。下に2つ横に並べ、その上に1つ。上の1つだけ淡いテラコッタで塗る。
足元に、地面を表す横線を1本だけ淡いグレーで引く。
画面の右半分は大きく空けておく。
```

**B案｜積み木だけ（いちばん事故が少ない）**
```
題材：画面の中央に、小さな積み木が3つだけ。角の丸い四角。
下に2つ横に並べ、その上に1つ。上の1つだけ淡いテラコッタで塗る。
その下に、置かれている面を表す横線を1本だけ淡いグレーで引く。
まわりは何も描かず、余白のままにする。
```

**C案｜どうしても「手のひら」を出したいとき**
```
題材：手のひらを正面から見た絵。ただし、指の関節や爪などの細部は一切描かず、
輪郭線1本だけの、極限まで単純化した形にする。指は親指1本＋他4本の合計5本。
手のひらの中央に、小さな積み木が3つのっている（下に2つ、上に1つ）。
上の1つだけ淡いテラコッタで塗る。手首は画面の下端で切る。
```

## 直したいときの言い方（そのまま送れる）

| 気になる点 | 送る言葉 |
|---|---|
| 線が太い・重い | 線をもっと細く、全体で均一の太さにしてください |
| 影がついた | 影とグラデーションを完全に取り除き、フラットな線画にしてください |
| 背景に質感が出た | 背景を完全な無地の単色にしてください。紙の質感やムラを入れないでください |
| 人に顔がついた | 人は頭の丸1つと上半身のアーチ1本だけにしてください。顔・手・足は描かないでください |
| 色が多い | 色は朱と淡いテラコッタだけ。しかも画面のごく一部だけにしてください |
| 積み木が大きい | 積み木をもっと小さくしてください |
| ごちゃつく | 要素を減らして、余白をもっと大きく取ってください |
| 描き込みすぎ | 線の本数を減らして、もっと単純な図形の組み合わせにしてください |

## 正直な注意

1. **色（hex）は守られません。** どのAIも近い色にするだけです。スライドに置くときは、
   絵の背景色をスポイトで拾って**スライド側の背景色を絵に合わせる**のがいちばん早い。
2. **同じチャットを使い続けること。** 別チャットで作ると絵柄が揃いません。
3. **人の描き方が崩れたら即座に直す。** GPTは放っておくと必ずキャラクター化します。
   1枚目で崩れたまま進めると、以降ずっと引きずります。
4. このフォルダの **SVG は保険**です。生成AIで詰まったら、SVGなら色・配置・大きさを
   無劣化で微調整できます。
