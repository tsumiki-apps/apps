# つみきクリップ（Mac のコピー履歴）

メニューバーに常駐して、コピーしたものをためておき、あとから選んで貼るアプリ。アイコンは明るい地に重なった2枚のカードと積み木ひとつ（`Icon.swift` でコードから描く。メニューバーは1色のテンプレート）。

| 操作 | キー（既定） | 中身 |
|---|---|---|
| 開く | ⇧⌘V | 画面の下に帯。新しい順にカードが並ぶ。打てばすぐ検索 |
| 順番に貼る | ⇧⌘C | オンの間にコピーしたものを、⌘V を押すたびに前から1つずつ貼る。最後まで貼ると止まる。もう一度 ⇧⌘C でやめる |

帯の中のキー：
- ← → で選ぶ、Enter で貼る、⇧Enter で書式なし、⌘1〜9 でその番号を貼る（⇧ を足すと書式なし）
- ⌘← ⌘→ で札（履歴・ピンボード）を切り替える、⌘⌫ で消す、⌘, で設定、Esc で閉じる（検索中は検索を消す）
- 右クリック：貼る・書式なしで貼る・整えて貼る（前後の空白を取る／改行をつなぐ／全角英数を半角に）・ピンボードへ・名前を付ける・消す
- カードはドラッグでほかのアプリへ持っていける

## 記録するもの・しないもの
- 記録する：文字（書式つきなら書式も）・リンク・画像（PNG で保存）・ファイル（場所だけ。中身は写さない）
- 記録しない：
  - パスワード管理アプリなどが「隠す」「一時的」「自動」の印を付けたコピー（`org.nspasteboard.ConcealedType`・`TransientType`・`AutoGeneratedType` ほか）
  - 「記録しないアプリ」に入れたアプリが手前にあるときのコピー（既定でパスワード・キーチェーンアクセス・1Password・Bitwarden など。設定の＋−で変えられる）
  - 一時停止中（メニューの「一時停止」。停止中はメニューバーのアイコンが薄くなる。再起動しても停止のまま）
  - 大きすぎるもの（文字 1MB・画像 30MB を超えるもの）
- 限界：手前のアプリは 0.3 秒ごとに見ている。記録しないアプリから切り替えた直後のコピーも記録しないようにしているが、印を付けないアプリで 0.3 秒より速く2回切り替えると見逃しうる
- 同じものをもう一度コピーすると、1つにまとめて一番上へ（同じ中身のまま動かす）

## 置き場と消し方
- 履歴はこの Mac の中だけ：`~/Library/Application Support/TsumikiClip/`（フォルダは 0700・ファイルは 0600＝自分だけ読める）。ネットにつながるコードは持たない（build.sh と package.sh が毎回 grep で確かめる）
- 残す期間：1日／1週間／30日（既定）／1年／ずっと。件数：200／1000（既定）／5000／上限なし。古いものから自動で消える（1時間ごと・起動時）
- ピンボードに入れたものは期間・件数で消えない。履歴を全部消しても残る
- Time Machine などのバックアップには入れない（置き場にバックアップ対象外の印）
- 履歴ファイルが壊れて読めないときは `clips.corrupt-<日時>.json` として横に残し、知らせてから新しく始める（空で上書きしない）。どこからも指されていない画像は起動時に消す
- 消し方：カードの右クリック →「消す」か ⌘⌫／メニューか設定の「履歴を全部消す」／アプリごと消すなら上のフォルダを消し、設定も消すなら `defaults delete com.tsumiki.clip`

## 許可
- アクセシビリティ：直接貼る（⌘V を送る）・順番に貼るに要る。無くても、選んだものはクリップボードに入るので自分で ⌘V できる（許可の案内は起動中に1回だけ）。許可した直後に順番に貼るが始められないときは、知らせが出る＝アプリを開き直す
- 貼り付け（macOS 15.4 以降）：コピーを読むのに要る。「毎回聞く」だと聞かれ続けるので、システム設定 → プライバシーとセキュリティ → 貼り付け で「許可」に

## 作り
```
./build.sh                       # 自己テスト（記録する・しない・まとめ・ファイル・画像・書式・整える・検索・ピンボード・期間と件数・権限・読み直し・順番に貼る・キー・帯の並びとキー操作）→ ~/Applications/つみき/TsumikiClip.app
./package.sh <出力.zip>          # Apple シリコン＋Intel の両対応・開発者証明書で署名
./notarize.sh <出力.zip>         # Developer ID で署名 → 公証（保存名 tsumikishot）→ staple → spctl で確認 → zip
build/TsumikiClip --shot <png>   # 架空の中身で帯を描く（明るい版と -dark 版）
```
- 試すときは `TSUMIKI_CLIP_DIR=<一時フォルダ>` で本番の履歴と分ける。`TSUMIKI_CLIP_DEBUG=1` を足すと、その置き場の `debug.log` に帯のキーの流れを書く（中身は書かない）
- 帯の検索欄では ⌘V・⌘C・⌘A・⌘Z が効く（編集メニューを自前で持つ）。日本語の変換中は Enter・矢印・Esc を変換に渡す
- 順番に貼るの ⌘V は、つみきクリップ自身が手前のとき（帯の検索・設定）は進めない。待っている分は期間・件数の上限でも消さない
- 帯は出すときにつみきクリップを手前にし、閉じる・貼るときに元のアプリへ戻す（手前にしないまま出すと、キーを1つ押した時点で受け手を外される）
- ファイル：`main.swift`（メニュー・起動）・`Store.swift`（保存・設定・色・整える）・`Clipboard.swift`（見張り・貼る・順番に貼る）・`Strip.swift`（帯）・`Settings.swift`・`Keys.swift`（キー）・`Icon.swift`・`SelfTest.swift`
